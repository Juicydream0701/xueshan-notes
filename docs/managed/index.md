# 笔记资料管理

这里是一个与课程笔记分开的资料空间。爱班资料和整理后的经验笔记已放入独立动态资料库；你可以在后台上传 Markdown、PDF 和附件。本地整理课程笔记、更新主站时，不会覆盖动态资料库内容。

<div class="managed-hero" markdown>

## 在线管理入口

公开资料可直接浏览；管理员从独立登录页进入后台，完成资料上传、排序和 Markdown 修改。

[浏览动态资料库](https://xueshan-notes-library.onrender.com/){ .md-button .md-button--primary }
[管理员登录](https://xueshan-notes-library.onrender.com/login){ .md-button }

</div>

!!! info "当前状态"
    动态资料库已部署在 Render Free。首次打开可能需要等待服务唤醒；免费实例休眠或重启后，运行时上传的文件可能丢失。GitHub 中的初始整理笔记会随服务启动恢复。

## 资料分区

| 分区 | 用途 | 更新方式 |
| --- | --- | --- |
| 在线资料 | 独立后台上传的补充笔记和附件 | 登录后台后添加或修改；免费实例不保证长期保存 |
| 公开资料 | 动态资料库中的 Markdown、PDF 和其他文件 | 上传后在资料库公开展示 |
| 课程笔记 | 本地项目维护的系统课程内容 | 本地提交并构建 |

## 计划支持的操作

- 新建、修改和删除指定目录中的 Markdown 笔记；
- 上传 PDF、图片和其他学习附件；
- 在线编辑已上传的 Markdown 笔记；
- 通过文件夹、文件名和拖动排序管理资料；
- 保持动态资料与静态课程笔记相互独立。
