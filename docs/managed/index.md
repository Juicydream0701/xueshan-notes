## 资料分区

| 分区 | 用途 | 更新方式 |
| --- | --- | --- |
| 在线资料 | 独立后台上传的临时资料、补充笔记和附件 | 登录后台后添加或修改 |
| 公开资料 | 已审核、允许访客阅读的 Markdown 和 PDF | 后台发布后同步显示 |
| 课程笔记 | 本地项目维护的系统课程内容 | 本地提交并构建 |

## 计划支持的操作

- 新建、修改和删除指定目录中的 Markdown 笔记；
- 上传 PDF、图片和其他学习附件；
- 为资料填写标题、课程、标签和简介；
- 预览 Markdown，确认后发布到本站；
- 保留修改记录，避免本地发布覆盖在线资料。
