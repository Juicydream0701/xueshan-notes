# 关于这个网站

你好，我是雪山大地。

这里是我的公开笔记本：学习笔记是主线，生活记录是旁枝。希望它既能帮助未来的自己，也能让偶然路过的人找到一点有用的东西。

## 如何更新

1. 在 `docs/` 目录中新增或修改 Markdown 文件。
2. 在 `mkdocs.yml` 的 `nav` 中加入新的学习页面（生活文章会自动出现在“生活记录”栏目）。
3. 提交到 GitHub 的 `main` 分支。
4. GitHub Actions 自动构建并发布网站。

## 内容约定

- 学习笔记尽量写清楚“问题、理解、例子、还没解决的地方”。
- 生活文章可以更随意，保留日期和当时的感受。
- 不把密码、身份证号、私人联系方式和不适合公开的日记放进公开仓库。

## 技术说明

本站使用 [Zensical](https://zensical.org/) 生成，部署在 GitHub Pages。Zensical 由 Material for MkDocs 团队维护，免费开源，适合个人知识库和非商业个人网站。
