# 爱班导师团与学习方法

## 导师团

爱班大二开始安排导师团和科研训练。导师制度适合用来了解科研方向、训练文献阅读和项目表达；如果暂时还没有正式项目，可以先整理自己的课程实验、数学建模和代码成果，带着具体问题与导师交流。

## 理科课程的共同方法

最大的提醒是独立思考和独立完成任务。AI 能帮助解释和检查，但概念性问题容易被不同资料混杂，必须回到定理、定义和教材推导。期末复习时先自己画知识框架，再用学长姐资料查漏补缺；只看别人的思维导图，容易停留在被动接受。

做题时建议遵循：先审题、写已知与目标、画坐标或电路、说明定理前提、独立列式，再参考答案。物理量符号、积分上下限、正负号和参考方向必须前后一致。

## 学习时间安排

长期课程适合“课内理解 + 课外练习 + 阶段复盘”；短学期课程则要在第一周建立章节地图，避免拖到最后一周才发现知识之间没有连起来。实验报告应在实验后立即完成数据处理、图表和误差分析，给后续修改留时间。
