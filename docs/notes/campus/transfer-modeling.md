# 专业发展与数学建模

## 院内转专业：电气 → 电子信息工程

转专业经历了两次。第一次面试失败，主要反思是高中和大一上缺少实际动手经历，绩点也不够突出。大一下开始参加多次数学建模比赛并积累奖项，第二次面试时形成了更具体的项目经历，最终在九进六的竞争中转入电子信息工程。

经验是：平时有空就积累可展示的项目、竞赛和动手经历，面试时能具体说明“做过什么、遇到什么问题、如何解决”，比只说兴趣更有说服力。

## 数学建模的价值

数学建模并不只是学习更多算法。更重要的是，在有限时间内理解陌生问题、建立可解释的模型、获得可信结果，并把全过程组织成一篇逻辑完整的论文。参加美赛、校赛、火花杯和国赛等比赛时，完整实战比只看算法教程更能暴露问题。

准备时建议：

1. 先阅读优秀论文，观察问题分析、模型建立、结果展示、摘要和检验的共同规律。
2. 熟悉 Python 数据处理、绘图、优化和统计工具，但不追求一次学完全部算法。
3. 提前进行一到两次完整模拟，测试选题、分工、代码交接和论文写作流程。
4. 组队时形成模型、编程、资料、图表和写作的互补分工，同时保持全队对整体思路的共同理解。
5. 正式比赛中让建模和论文同步推进，每完成一问就整理模型、公式、结果与解释。

不要把 AI 的可运行代码直接等同于正确模型。数据泄漏、约束条件、指标定义、结果解释和学术诚信都要由自己检查。竞赛规则对 AI 的要求每年可能不同，应以当年官方规则为准。
