# 03 预测与分类模型

## 1. 先做基线，再增加复杂度

预测问题的第一版应有一个可解释基线：均值预测、最近一期值、线性回归或简单逻辑回归。基线的作用是回答“复杂模型到底增加了多少价值”。若复杂模型只在训练集上更好，却没有在验证集改善，就不应直接采用。

## 2. 回归任务

线性回归写成

$$\hat y=\beta_0+\sum_{j=1}^{p}\beta_jx_j,$$

用最小二乘估计参数。它适合关系近似线性、需要解释变量方向的场景。遇到多重共线性，可用岭回归或 Lasso；遇到明显非线性，可比较决策树、随机森林、梯度提升和 SVR。

评价回归时同时报告：

$$\mathrm{MAE}=\frac1n\sum_i|y_i-\hat y_i|,$$

$$\mathrm{RMSE}=\sqrt{\frac1n\sum_i(y_i-\hat y_i)^2},$$

$$R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y)^2}.$$

MAE 易解释且对异常值较稳健；RMSE 会放大大误差；$R^2$ 只能表示相对拟合程度，不能替代业务误差。

## 3. 分类任务

二分类的基本输出包括真阳性、真阴性、假阳性和假阴性。由此得到：

$$\mathrm{Precision}=\frac{TP}{TP+FP},\qquad
\mathrm{Recall}=\frac{TP}{TP+FN},$$

$$F_1=\frac{2\,\mathrm{Precision}\,\mathrm{Recall}}
{\mathrm{Precision}+\mathrm{Recall}}.$$

类别严重不平衡时，准确率可能造成误判，应报告混淆矩阵、召回率、精确率、F1 和 ROC-AUC/PR-AUC，并说明哪个错误更昂贵。

## 4. 模型选择建议

| 数据特征 | 首选尝试 | 需要留意 |
| --- | --- | --- |
| 样本少、解释要求高 | 线性/逻辑回归 | 共线性、尺度 |
| 非线性、特征混合 | 决策树、随机森林 | 过拟合、特征重要性偏差 |
| 样本中等、边界复杂 | SVM/SVR | 标准化和参数 $C,\gamma$ |
| 时间序列 | 滞后特征、ARIMA 或状态空间 | 时间顺序和滚动验证 |
| 任务含不确定性 | 集成模型、Bootstrap | 置信区间和稳定性 |

## 5. 交叉验证与调参

K 折交叉验证把训练集分成 $K$ 份，轮流验证。分类任务应使用分层 K 折，时间序列使用滚动窗口，不能随机打乱未来信息。调参时只在训练集内部交叉验证，最终测试集只使用一次。

调参记录应包含：参数范围、评价指标、最优参数、均值和标准差。若两个参数组合性能相近，优先选择更简单、解释性更好的模型。

## 6. 结果解释

不要只展示一个最高分。回答三个问题：模型在哪些样本上失败？误差是否集中在某类或某个时间段？改变关键特征后预测是否符合常识？特征重要性、部分依赖和误差分组都只能提供线索，不能自动证明因果关系。

## 7. 可复现实验

固定随机种子，保存训练/验证划分、预处理参数、模型版本和评价脚本。表格中的结果都应能由代码重新生成。网站中的[预测模型讲义](resources/prediction-model.pdf)和[分类模型讲义](resources/classification-model.pdf)用于查阅算法步骤。
