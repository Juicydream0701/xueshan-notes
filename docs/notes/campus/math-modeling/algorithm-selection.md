# 05 算法选择：六类工具放回题型

## 1. 选择算法的顺序

先看输出类型和约束，再看数据规模、噪声、可解释性和时间预算。一个实用决策顺序是：

1. 结果是预测、分类、排序、路径、分配还是评价？
2. 变量是连续、整数还是二元？
3. 目标和约束是否线性或凸？
4. 数据是否足够，是否有标签，是否带时间顺序？
5. 是否需要严格最优、可解释，还是允许近似解？
6. 用简单基线和候选方法做小规模比较。

## 2. 现代优化算法

遗传算法、粒子群和模拟退火适合非凸、离散或黑箱目标。它们的优势是能探索复杂解空间，缺点是难以证明全局最优，且参数和随机性影响较大。报告中应给出可行率、迭代曲线和多次运行统计。

## 3. 蒙特卡洛与仿真

当解析计算困难、系统含随机过程或需要估计概率时，用随机抽样近似期望：

$$\hat\mu_N=\frac1N\sum_{i=1}^{N}g(X_i).$$

样本量增加时误差通常按 $O(N^{-1/2})$ 下降。应报告置信区间、重复次数和随机种子；不要把一次仿真输出当成确定结论。

## 4. 规划与图网络

路径、调度和状态转移问题可建成图：节点表示状态或地点，边表示动作、连接或转移成本。Dijkstra 适合非负边权的单源最短路；Bellman–Ford 可处理负边但计算更慢；A* 通过启发函数加速搜索；最大流和最小费用流适合容量与流量问题。

建模时要说明节点、边、权重和不可达条件。交通或通信题中，边权的单位和是否随时间变化尤其重要。

## 5. 统计与机器学习

预测、分类和评价模型属于数据驱动方法，重点是泛化误差、数据划分、特征工程和评价指标。使用神经网络或复杂集成前，先问：样本是否足够、标签是否可靠、结果是否需要解释、能否在限时内完成验证。

## 6. 排序、规则与后处理

排序通常不是完整模型，却常用于指标排名、候选方案筛选和结果展示。先定义排序指标，再处理并列、缺失值和权重。若排名用于决策，最好给出排名对权重变化的敏感性，而不是只展示一个固定顺序。

## 7. 算法组合的边界

组合模型要说明每一步输入和输出。例如“聚类—评价—优化”流程中，聚类标签如何进入评价，评价结果如何约束优化，误差如何传递。每增加一种算法，都要有明确目的：提升精度、降低计算量、处理约束或增强解释。为了显得复杂而堆叠算法，会增加错误和复核成本。

可配合[六大算法讲义](resources/six-algorithms.pdf)快速查阅，但正式论文应补充适用条件、参数和验证结果。
