# 02 数据处理与论文表达

## 1. 数据字典先于代码

拿到 Excel 或 CSV 后先建立数据字典：列名、含义、单位、时间范围、缺失比例、异常规则和数据来源。不要直接在代码里写一串无法解释的列索引。对于竞赛数据，建议保留三份文件：原始只读副本、清洗后的中间表、最终建模表。

## 2. 清洗流程

### 缺失值

区分“没有发生”“没有记录”和“未知”。均值填充只适用于缺失机制简单且变量分布稳定的情况；时间序列可考虑前向填充或插值；关键字段缺失时应报告删除样本数，并做敏感性比较。

### 异常值

先用箱线图、散点图和分位数定位，再判断它是录入错误、测量误差还是题目真正关心的极端事件。删掉异常值前要留下依据。对于网络安全、灾害等问题，极端值可能就是最重要的信号。

### 尺度处理

线性模型、KNN、SVM、聚类和神经网络通常需要标准化：

$$z_i=\frac{x_i-\mu}{\sigma}.$$ 

树模型对单调尺度变换不敏感，但混合模型中仍要统一单位。标准化参数只能在训练集上拟合，再用于验证集和测试集，以避免数据泄漏。

## 3. 探索性分析

用三组图回答三类问题：

- **分布图**：变量是否偏态、是否存在长尾；
- **关系图**：变量之间是否线性、分段或存在交互；
- **结构图**：时间趋势、空间分布、群组差异是否明显。

每张图都要有标题、单位、样本范围和一句结论。图不是装饰，例如“网络使用率总体上升”还应说明增速在哪些年份改变、哪些地区偏离趋势、这种差异是否会影响模型。

## 4. 论文的最小完整结构

1. **摘要**：背景、方法、代表性结果、结论和关键词；
2. **问题重述**：只保留影响建模的关键信息；
3. **问题分析**：说明每问的难点和小问之间的关系；
4. **模型假设与符号说明**：简洁、可检查；
5. **模型建立与求解**：公式、算法、参数和实现；
6. **结果与分析**：表格、图、数值解释和稳健性；
7. **模型评价与推广**：优点、局限、改进条件；
8. **参考文献与附录**：数据源、代码说明和补充推导。

## 5. 图表与引用

正文中的图表应做到“看图能知道结论”。表格避免堆满小数，统一有效数字和单位；比较不同方法时使用同一评价指标和同一测试集。参考文献要核对作者、标题、年份和链接，不把模型生成的引用直接当成事实。

## 6. 数据泄漏检查清单

- 目标变量或未来信息是否意外进入特征；
- 标准化、插值和特征选择是否在全数据上提前完成；
- 同一对象的重复记录是否同时出现在训练和验证集；
- 时间序列是否把未来样本用于过去预测；
- 结果图是否使用了测试集调参。
