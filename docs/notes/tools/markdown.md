# Markdown 写作入门

Markdown 是一种很轻量的纯文本写作方式。它让内容和排版分开，适合长期保存，也方便转换成网页。

## 常用语法

```markdown
# 一级标题
## 二级标题

**加粗**、*斜体*、`代码`

- 无序列表
- 第二项

[链接文字](https://example.com)
```

## 代码和公式

```python
def hello(name: str) -> str:
    return f"你好，{name}！"
```

行内公式可以写成 `$E=mc^2$`，独立公式可以写成：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

## 写作建议

- 一个页面只解决一个主要问题。
- 标题层级尽量清楚，不要跳级。
- 图片放在文章附近，并写一句说明。
- 先写内容，最后再调整目录和样式。
