# 怎样使用课程笔记与原始资料

找课程时从[课程总览](../courses/index.md)进入，也可以沿左侧的“专业主线、数学基础、物理、编程、通识”浏览。下面几类页面用途不同，不必每次都从课程第一页开始读。

| 页面类型 | 适合什么时候看 | 怎么使用 |
| --- | --- | --- |
| 课程总览 | 不知道章节关系或先修要求 | 先确定自己缺的环节，再进入专题 |
| 详细讲义 | 第一次理解、基础不稳、综合题不会选方法 | 阅读推导和例题，自己完成关键步骤，再看练习解答 |
| 复习路线与速查提纲 | 已学过，考前定位方法或公式 | 先核对适用条件，遇到不明白的地方回详细讲解 |
| 原始PDF | 需要完整题图、课堂顺序或更多练习 | 对照具体页码阅读；PDF中的符号未必与网页完全相同 |
| 经验记录 | 了解学习安排、实验复盘和选课思路 | 当作个人经历参考，成绩和考试范围因人、因学期而异 |

## 从一道不会的题开始

假设你会RC公式，却不知道开关换路后该用哪个电阻。先到[电路动态讲义](../courses/circuit-theory/topics/05-transients.md)，看初值、终值、端口等效的推导，再做该页的数值例题。最后打开相邻的课件页对照题图，省去逐份翻找PDF的时间。

本站的课程深度仍有差别：电路原理现按讲义组织，其他课程中仍有部分页面是提纲。短提纲的用途是导航和速查，并不代表对应知识点只需要学这几行。遇到需要进一步推导的地方，优先回到配套课件和教材。

## 公式与解答

公式在浏览器内排版，长式可横向滚动。题目中的电压、电流方向、有效值/峰值、初始条件和线性假设是答案的一部分，不能只复制最后一行。练习解答可以折叠，建议先写出自己的方程，再展开核对。

如果网页与原讲义答案不一致，先逐项比较题设、符号和模型，再做独立验算。明确发现的错误会更正并说明原因；尚未核实的旧PDF不会被悄悄改写成另一份资料。

## PDF怎么打开

[PDF资料中心](pdf-library.md)按任务和课程找文件，[PDF阅读器](pdf-reader.md)支持站内资料、本地打开和调整高度。点击网页里的PDF链接可以直接阅读；需要对照时用新标签页。某些手机浏览器不提供完整内嵌PDF能力，可以使用阅读器里的新标签页入口。

原资料按用途精选，不把相同文件反复上传。网页与PDF交叉引用时，页码一律尽量使用PDF阅读器中的物理页序，避免和讲义印刷页码混淆。
