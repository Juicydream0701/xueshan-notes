## 一个简单的笔记模板

```markdown
# 主题名称

## 我想解决什么问题？

## 核心概念

## 一个例子

## 我的理解

## 还没有解决的问题

## 参考资料
```

不用每次都写完整模板，先保留思考痕迹，后续再整理也可以。
