# 中国近现代史纲要

## 1. 用时间线建立骨架

复习历史不能只堆事件名称。先按“外部冲击—社会结构—政治选择—结果与影响”建立时间线，再把重要事件放进这条因果链。建议每个阶段只保留三个关键词：主要矛盾、关键转折、历史评价。

## 2. 从晚清变局到早期探索

近代中国面临国家主权受损、经济结构变化和社会动员方式更新等多重压力。洋务、维新、革命等探索的差异，不只在口号，也在所依靠的社会力量、制度方案和组织能力。回答论述题时，应同时写出历史条件、尝试内容和局限。

## 3. 新民主主义革命的组织与动员

理解革命进程要关注农村与城市、统一战线、武装斗争和党的建设之间的关系。把“为什么选择某条道路”与“这条道路如何取得资源和群众支持”结合起来，答案会比事件罗列更完整。

## 4. 社会主义建设与改革开放

新中国成立后的制度建设、工业化探索和改革开放，是连续又有阶段差异的过程。复习时区分目标、政策工具和实际效果，既看到成就，也记录调整和经验教训。历史评价要基于材料和时代条件，避免用今天的结论简单替代当时的选择。

## 5. 资料与答题模板

论述题可以使用“背景—问题—方案—结果—意义/局限”五段式；材料题先圈出时间、主体、动词和评价词，再判断材料属于哪一阶段。资料入口：[近代史总览](resources/modern-history-overview.pdf)。
