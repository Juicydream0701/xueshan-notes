# 通识与生活学习

这里整理与专业课程并行的通识学习：语言表达、心理健康、历史视野、法治意识、创业实践和科研方法。它们不以“背完一套题”为终点，而是帮助我把知识放进真实生活：能读懂材料、能做出判断、能照顾自己，也能把想法变成可执行的项目。

| 课程 | 入口 | 适合解决的问题 |
| --- | --- | --- |
| 大学英语与表达 | [进入课程](college-english.md) | 读论文、写摘要、做口头汇报 |
| 心理健康与心理咨询 | [进入课程](mental-health.md) | 识别压力、建立边界、寻求支持 |
| 中国近现代史纲要 | [进入课程](modern-china-history.md) | 用时间线和因果链理解历史 |
| 马克思主义基本原理 | [进入课程](marxism.md) | 把概念用于分析现实问题 |
| 法学基础 | [进入课程](law-basics.md) | 形成证据、规则和风险意识 |
| 创业基础 | [进入课程](entrepreneurship.md) | 从需求发现走到验证和复盘 |
| 科学创新方法论及实践 | [进入课程](innovation-methods.md) | 提出问题、设计实验、表达结论 |

## 使用方式

每门课都按“核心概念 → 生活迁移 → 复习与行动”组织。公开站点只保留通用讲义和方法卡，不上传成绩、名单、个人作业或心理咨询隐私。涉及心理困扰、法律纠纷或医疗问题时，课程笔记不能替代专业帮助。
