# 法学基础

## 1. 规则、权利与责任

法律分析的第一步是识别事实和关系：谁做了什么、造成什么结果、双方有哪些权利义务。再判断适用的法律部门和责任类型。把道德评价、合同约定和法律责任分开，能减少“觉得不公平就等于违法”的误判。

## 2. 证据与程序

证据要关注来源、形成过程、关联性和完整性。保存合同、聊天记录、付款凭证时要保留原始载体和时间信息。程序不是形式负担，它决定当事人如何陈述、举证、申辩和救济。

## 3. 合同与网络生活

网购、租房、实习和软件服务都可能形成合同。阅读条款时重点看标的、期限、价格、违约责任、自动续费、个人信息使用和争议解决。不要只截一张页面，重要条款要保存完整版本。

## 4. 科技与工程风险

自动驾驶、人工智能和数据系统涉及产品责任、隐私保护、知识产权和安全合规。工程设计中应记录需求、测试、警示和异常处理，把“可用”与“可证明安全”区分开。

## 5. 遇到纠纷的行动顺序

先停止扩大损失，保留证据，再向对方提出清晰请求；无法解决时咨询学校法律援助、消费者协会或专业律师。公开网站只做课程学习，不提供针对具体案件的法律意见。
