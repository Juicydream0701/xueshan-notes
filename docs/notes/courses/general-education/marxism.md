# 马克思主义基本原理

## 1. 哲学：从联系和发展看问题

唯物辩证法强调世界处在普遍联系和永恒发展中。分析一个现实问题时，先找主要矛盾和矛盾的主要方面，再区分条件、阶段与边界。质量互变与否定之否定的分析应结合事物发展的具体过程、转折条件和阶段特征。

## 2. 认识论：实践、认识与检验

认识从实践中来，又要回到实践中检验。做实验或做项目时，假设、测量、反馈和修正构成一个循环。既不能把一次经验当成全部规律，也不能因为模型不完美就放弃对规律的逼近。

## 3. 政治经济学：商品、劳动与资本

商品具有使用价值和价值，价值量与社会必要劳动时间相关。理解资本、剩余价值和生产关系时，先把概念放进生产过程和分配关系中，再结合现实案例讨论技术、劳动和组织的变化。

## 4. 社会发展与个人选择

历史唯物主义关注生产力、生产关系、经济基础和上层建筑的相互作用。个人规划不能脱离社会条件，但也不意味着个人没有主动性。把宏观趋势转成自己的能力清单和行动节奏，是学习这门课的实际收获。

## 5. 复习方法

用“概念定义—相互关系—现实例子—边界条件”做四格卡片。论述题先写核心概念，再说明它们之间的因果或条件关系，最后用材料验证，不要只堆砌熟悉的政治术语。
