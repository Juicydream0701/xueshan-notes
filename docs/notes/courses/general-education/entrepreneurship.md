# 创业基础

## 1. 从问题而不是点子出发

好的项目起点是一个可观察、反复发生且有人愿意解决的问题。访谈时问对方最近一次遇到什么困难、现在如何解决、为此付出了什么成本，而不是直接推销自己的方案。

## 2. 用户画像与价值主张

把用户按场景、任务和痛点描述，而不是只写年龄和身份。价值主张要说清“为谁、在什么场景、减少什么成本或增加什么收益”。如果一句话不能让陌生人复述，说明仍然太宽泛。

## 3. 最小可行产品与验证

MVP 是用最低成本验证关键假设的版本，可以是手工服务、原型页面或小范围试用。每次测试只验证一两个假设，预先写下成功指标和停止条件，避免事后挑选有利数据。

## 4. 商业模式与资源边界

记录收入来源、成本结构、获客方式和交付能力。学生项目尤其要考虑时间、团队分工、知识产权和数据合规，不要为了“看起来像公司”而过早增加固定成本。

## 5. 路演与复盘

路演按照问题、用户、方案、证据、商业模式、团队和下一步展开。复盘要写“原假设—实际数据—差异原因—下一轮实验”，把失败变成可复用的判断依据。
