# 科学创新方法论及实践

## 1. 把兴趣变成问题

研究问题需要对象、变量、范围和可验证结果。先做文献和现状检索，确认问题是否已经被充分解决，再写出自己的差异点。一个好的问题可以被拆成几个互相衔接的小问题。

## 2. 假设与证据链

假设要能导出预测，预测要能通过实验、数据或文本材料检验。记录变量定义、控制条件、数据来源和失败样本，才能让别人复现你的结论。结论强度不能超过证据强度。

## 3. 实验与数据质量

实验前写方案和预期结果，实验后保留原始数据、版本和异常记录。区分重复测量、对照实验和观察性数据；报告均值时同时说明样本量和不确定性，不要只展示最漂亮的一组结果。

## 4. 迭代与团队协作

将项目拆为里程碑，每个里程碑都有可交付物和复盘时间。使用统一的文件命名、版本记录和会议结论，减少“只有某个人知道”的隐性知识。分歧应回到假设和数据，而不是回到职位或声音大小。

## 5. 科学表达与伦理

图表要标注单位、样本量和误差；引用要可追溯；涉及人或个人数据时要取得同意并做匿名化。创新的价值不仅在于新，也在于诚实、可复现和对现实有帮助。
