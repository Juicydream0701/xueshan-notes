# 专题六：级数、幂级数与积分变换

## 1. 数项级数的判断路线

面对 $\sum a_n$，先看通项是否趋于零；若不趋于零，级数必发散。正项级数优先尝试比较、极限比较、比值、根值和积分判别。比较时要选择同阶的基准级数，例如 $1/n^p$ 或几何级数，不能只比较单个项的大小趋势。

交错级数可用莱布尼茨判别：绝对值单调递减且趋于零时收敛。收敛后还要区分绝对收敛与条件收敛，因为重排性质和误差估计不同。交错级数余项不超过下一项绝对值，是很实用的误差界。

## 2. 幂级数的收敛域

对 $\sum a_n(x-x_0)^n$，比值法通常得到收敛半径 $R$。先处理内部 $|x-x_0|<R$ 和外部 $|x-x_0|>R$，再单独代入两个端点。端点不能由半径直接判断，可能出现条件收敛、绝对收敛或发散三种情况。

在收敛区间内部，幂级数可以逐项求导和逐项积分。求导会改变系数但不改变收敛半径，积分也一样；端点需要重新判断。用幂级数解题时，先写中心点、半径和端点，再写展开式，避免只给一个形式答案。

## 3. 泰勒展开的选择

常用基本展开为

$$e^x=\sum_{n=0}^{\infty}\frac{x^n}{n!},\quad \sin x=\sum_{n=0}^{\infty}(-1)^n\frac{x^{2n+1}}{(2n+1)!},$$

$$\ln(1+x)=\sum_{n=1}^{\infty}(-1)^{n-1}\frac{x^n}{n},\quad \frac1{1-x}=\sum_{n=0}^{\infty}x^n.$$

复杂函数尽量通过代换、乘积、求导或积分从基本展开得到。题目若要求某阶近似，要保留到第一个可能影响误差的项；若要求极限，比较最低非零阶即可。

## 4. 傅里叶级数的结构

周期函数可分解为正弦和余弦的叠加。区间 $[-L,L]$ 上的系数为

$$a_n=\frac1L\int_{-L}^{L}f(x)\cos\frac{n\pi x}{L}\,dx,\quad b_n=\frac1L\int_{-L}^{L}f(x)\sin\frac{n\pi x}{L}\,dx.$$

偶函数只保留余弦项，奇函数只保留正弦项。分段光滑函数在连续点收敛到函数值，在跳跃点收敛到左右极限平均值。利用奇偶性和正交性可以显著减少计算量。

## 5. 拉普拉斯变换与微分方程

拉普拉斯变换把时域微分方程变成复频域代数方程：

$$\mathcal L\{f'(t)\}=sF(s)-f(0^+),\qquad \mathcal L\{f''(t)\}=s^2F(s)-sf(0^+)-f'(0^+).$$

应试时按“写初值—变换两边—整理 $F(s)$—部分分式—逆变换”执行。延迟函数和阶跃函数需要统一的单位阶跃记号，避免把开关时刻误当成函数中心。最终可用初值定理、终值定理或代回原方程检查。

## 6. 常见失分点

- 只写收敛半径，不判断端点；
- 把条件收敛误说成绝对收敛；
- 傅里叶系数漏掉区间长度因子；
- 拉普拉斯变换漏掉初值项；
- 级数近似没有说明误差来源。

## 7. 代表题：幂级数的端点

对 $\sum_{n=1}^{\infty}\frac{(x-2)^n}{n}$，比值法得到 $R=1$，先写出内部区间 $1<x<3$ 和外部发散区间，再单独检查 $x=1,3$。在 $x=1$ 时得到交错调和级数，条件收敛；在 $x=3$ 时得到调和级数，发散。因此收敛区间是 $[1,3)$。写成这三步比只给半径更完整。

## 8. 误差与近似的选择

若使用交错级数前 $N$ 项近似，误差不超过第 $N+1$ 项绝对值；若使用泰勒公式，可用余项的最大导数上界估计误差。实际计算先判断题目给的 $x$ 是否靠近展开中心，再选择麦克劳林、在 $a\ne0$ 处展开，或直接采用数值积分。级数项虽然可逐项计算，但不代表截断后一定满足精度要求。
