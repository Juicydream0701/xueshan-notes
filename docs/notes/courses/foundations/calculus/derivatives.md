# 专题二：导数、微分与中值定理

## 1. 导数是局部线性化

导数 $f'(x_0)$ 是差商在 $x_0$ 处的极限，也表示曲线切线斜率。若函数可导，则一定连续，但连续不一定可导。绝对值函数在 0 处连续却不可导，是判断“连续/可导”区别的典型例子。

微分 $dy=f'(x)dx$ 是增量的线性主部。实际计算中，$dy$ 可用于误差估计：当输入误差为 $dx$ 时，输出误差首阶近似为 $|f'(x)dx|$。

## 2. 求导的结构识别

- 和、差、常数倍：逐项求导；
- 乘积：$(uv)'=u'v+uv'$；
- 商：$(u/v)'=(u'v-uv')/v^2$；
- 复合：链式法则，先对外层求导再乘内层导数；
- 反函数：$(f^{-1})'(y)=1/f'(x)$，需要 $f'(x)\ne0$；
- 隐函数：把 $y$ 看成 $x$ 的函数，对两边同时求导；
- 参数方程：$dy/dx=(dy/dt)/(dx/dt)$，二阶导还要再除以 $dx/dt$。

高频错误是漏掉链式法则、把隐函数中的 $y$ 当常数、或忘记参数曲线的方向和正则条件。

## 3. 中值定理家族

罗尔定理要求闭区间连续、开区间可导、端点值相等；拉格朗日中值定理给出某点的瞬时斜率等于割线斜率；柯西中值定理把两个函数的增量联系起来。证明题必须逐条检查条件。

中值定理的用途包括：

- 证明函数单调；
- 证明不等式；
- 估计函数增量；
- 证明方程根的唯一性；
- 推出洛必达法则。

## 4. 单调、极值与最值

求单调区间先找定义域，再求导并找临界点：$f'(x)=0$ 或 $f'$ 不存在的点。把临界点和定义域端点排序，逐区间判断导数符号。局部极值还要考虑导数不存在的尖点。

闭区间最值必须比较：

1. 所有内部临界点；
2. 两个端点；
3. 可能的不可导点。

只求出 $f'(x)=0$ 的点而不比较函数值，不能完成最值题。

## 5. 凹凸、拐点与曲线形状

二阶导数为正通常表示图像向上凹，为负表示向下凹。拐点要求凹凸性发生改变，不是“二阶导等于 0”就自动成立。渐近线、单调区间、极值、凹凸区间组合起来，才能完成完整作图。

曲率题常用
$$\kappa=\frac{|y''|}{(1+y'^2)^{3/2}}.$$
参数曲线要先把 $y'$ 和 $y''$ 转换正确，再代入曲率公式。

## 6. 泰勒公式与误差

在 $x=a$ 附近，
$$f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k+R_n(x).$$
麦克劳林展开是 $a=0$ 的特例。余项可以用拉格朗日型或佩亚诺型表示。题目若只问等价阶，写到首个非零项即可；若问误差范围，必须保留余项估计。

常见展开：$e^x$、$\sin x$、$\cos x$、$\ln(1+x)$、$(1+x)^\alpha$。展开前先判断收敛区间和变量是否足够小。

## 7. 应试模板

“讨论单调和极值”可按：定义域 → $f'$ → 临界点 → 符号表 → 单调区间 → 极值 → 端点比较。  
“证明不等式”可按：移项构造辅助函数 → 求导判断单调/最值 → 代入端点。  
“求近似值”可按：选择展开点 → 写阶数 → 给出余项或误差阶 → 计算。

## 8. 代表题：函数作图的完整顺序

以 $f(x)=x e^{-x}$ 为例，先由指数函数确定定义域，再求 $f'(x)=e^{-x}(1-x)$，得到 $x=1$ 是唯一临界点；接着用 $f'$ 的符号判断单调区间和极大值。若还要判断凹凸，再求 $f''(x)=e^{-x}(x-2)$，并检查 $x=2$ 两侧的符号变化。最后研究 $x\to\pm\infty$ 的极限，补上渐近行为。这个顺序能避免只算导数而漏掉定义域、端点和无穷远。

## 9. 线性化与误差控制

在 $x=a$ 附近，$f(x)\approx f(a)+f'(a)(x-a)$ 是切线近似。若 $|f''(x)|\le M$，则线性化误差满足 $|R_1|\le M|x-a|^2/2$。考试中若要求“误差小于某值”，先用这个上界倒推允许的 $|x-a|$，再决定测量精度或保留位数。不要把 $dy$ 当成精确增量，它只保留了一阶信息。
