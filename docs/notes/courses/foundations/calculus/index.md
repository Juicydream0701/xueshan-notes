# 微积分（甲）I–II：总览

微积分涵盖一元与多元函数、空间几何、微分、积分及级数。各章按定义、定理条件、推导和典型题组织，计算与证明均须核对适用条件。

## 六个专题入口

1. [极限、连续与一元函数](limits-continuity.md)：建立“趋近”和局部性质的语言。
2. [导数、微分与中值定理](derivatives.md)：把变化率变成可计算、可证明的工具。
3. [一元积分与积分应用](integrals.md)：用原函数、定积分和广义积分处理累积量。
4. [多元函数、向量与空间几何](multivariable.md)：从偏导推进到梯度、极值和曲面。
5. [重积分、曲线积分与曲面积分](vector-integrals.md)：用参数化、换元和积分定理处理空间问题。
6. [级数与积分变换](series.md)：用无穷过程逼近函数，并连接微分方程和信号分析。

## 统一的解题习惯

- 先写定义域、连续区间和可导区间，再使用定理。
- 看到极限先判断能否直接代入；不能时再考虑等价无穷小、泰勒展开、洛必达或夹逼。
- 看到导数先判断题目要的是切线、单调性、极值、估计还是证明。
- 看到积分先确认区间、换元是否一一、积分区域是否需要改写。
- 看到级数先判断正项/交错/幂级数，再决定比较、比值、根值、积分判别或阿贝尔判别。
- 所有最后结果都做一个数量级、符号或特殊值检查。

## 建议的六周回看安排

第一周只处理极限、连续和一元函数，把定义、等价无穷小、单调有界数列和函数连续性放在同一张公式卡上。第二周集中做导数、微分和中值定理，要求每道证明题先写定理条件，再写辅助函数。第三周回看积分，按“不定积分技巧—定积分几何意义—广义积分收敛”顺序练习。第四周进入多元函数，完成偏导、全微分、方向导数和极值的基础题。第五周专门画积分区域，练重积分、曲线积分、曲面积分以及三大积分定理。第六周收束到级数、傅里叶和拉普拉斯变换，用一套综合题检查各章节之间的转换。

每周都保留三类错题：概念条件遗漏、计算过程失误、方法选择错误。前两类可以通过重写定义和检查表解决，第三类要记录“为什么先想到这个方法、哪个信号提示了更好的方法”。这样复习笔记会逐渐变成自己的决策树，而不只是公式集合。
