# C 程序设计：专题笔记

## 专题一：类型、表达式与控制流

先区分整型、浮点型、字符型和指针类型，再判断隐式转换。整数除法会截断，比较浮点数要设置容差。条件和循环题先画流程，再处理边界和循环终止条件。

## 专题二：数组、字符串与内存

数组在内存中连续存储，函数参数中的数组会退化为指针。字符串以 `\\0` 结尾，`strlen` 不含结束符而 `sizeof` 可能包含它。任何下标都要证明在合法范围内，缓冲区溢出通常比语法错误更难发现。

## 专题三：函数、指针与作用域

C 语言按值传参；需要修改调用者变量时传入地址。指针题可画“变量—地址—目标”三层关系。局部变量、全局变量、静态变量和动态内存的生命周期不同，返回局部变量地址是典型错误。

## 专题四：结构体与动态数据结构

结构体把不同类型字段组合成一个对象，链表节点通常包含数据和下一个节点指针。插入、删除时先保存后继指针，再修改链接；空链表、头结点和单节点是必须单独测试的边界。

## 专题五：文件、调试与工程习惯

文本文件使用 `fopen`、`fgets`、`fprintf` 等接口，二进制读写要注意结构体对齐。编译错误、运行时错误和逻辑错误应分开排查。先用小输入验证，再用调试器观察变量和内存，最后才做性能优化。
