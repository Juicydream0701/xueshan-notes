# C 程序设计基础及实验

## 这门课解决什么问题？

C 语言训练的是把问题拆成数据、流程和函数。对电子信息专业来说，它还是后续微机原理、嵌入式实验和算法练习的第一种“可执行表达”。

## 学习主线

1. **表达式与控制流**：先把类型、运算符、分支和循环写准确。
2. **数组与字符串**：理解连续内存、下标和 `\0`，再处理输入输出。
3. **函数与作用域**：把重复逻辑封装起来，分清传值、传址和返回值。
4. **指针与结构体**：能画出变量、地址和指向关系，再写动态数据结构。
5. **文件与调试**：学会定位编译错误、运行错误和逻辑错误，最后再处理文件读写。

## 最小复习清单

- 能手算数组、指针和 `sizeof` 的结果；
- 能说明字符串结束符、数组参数和指针参数的区别；
- 能把一个长函数拆成多个职责明确的函数；
- 能用最小测试样例检查边界、空输入和越界；
- 能读懂编译器报错，并回到报错行附近寻找真正原因。

## 和专业课的连接

微机原理中的寄存器、地址和接口，本质上都需要先建立“数据在内存中的表示”这一层直觉。不要只背语法，建议把每个指针题都画成内存示意图。
