# C 程序设计基础及实验

## 课程内容

C 语言训练的是把问题拆成数据、流程和函数。对电子信息专业来说，它还是后续微机原理、嵌入式实验和算法练习的第一种“可执行表达”。

## 知识结构

1. **表达式与控制流**：先把类型、运算符、分支和循环写准确。
2. **数组与字符串**：理解连续内存、下标和 `\0`，再处理输入输出。
3. **函数与作用域**：把重复逻辑封装起来，分清传值、传址和返回值。
4. **指针与结构体**：能画出变量、地址和指向关系，再写动态数据结构。
5. **文件与调试**：学会定位编译错误、运行错误和逻辑错误，最后再处理文件读写。

## 复习要点

- 能手算数组、指针和 `sizeof` 的结果；
- 能说明字符串结束符、数组参数和指针参数的区别；
- 能把一个长函数拆成多个职责明确的函数；
- 能用最小测试样例检查边界、空输入和越界；
- 能读懂编译器报错，并回到报错行附近定位错误原因。

## 相关专业课程

微机原理中的寄存器、地址和接口，本质上都需要先建立“数据在内存中的表示”这一层直觉。不要只背语法，建议把每个指针题都画成内存示意图。

## 逐题训练路线

### 指针题：先画内存，再判断表达式

设 `int a[3] = {1, 2, 3}; int *p = a;`，则 `p` 指向 `a[0]`，`p+1` 指向下一个 `int` 元素，而不是地址只增加一个字节。数组名在表达式中通常退化为首元素指针，但 `sizeof(a)` 仍返回整个数组大小。处理指针自增、下标和函数参数时，先写出“对象—地址—类型”，再计算结果。

### 函数与数组

数组作为参数传入函数时实际传递首元素地址，函数内部无法仅凭参数名得到数组长度。因此接口应同时传入指针和元素个数，并约定是否允许空指针。修改数组元素是修改原对象，修改形参指针本身则只影响函数内部。

### 结构体与文件

结构体适合把一条记录的字段组织在一起；文件读写要明确文本/二进制模式、打开失败、读写返回值和关闭文件。对每个文件操作都保留错误分支，避免把 `fopen` 返回的空指针继续传给 `fscanf`。

### 调试清单

1. 编译错误：先看第一条报错，检查分号、括号、头文件和类型；
2. 运行错误：检查数组边界、空指针、未初始化变量和除零；
3. 逻辑错误：用最小输入逐步打印中间值；
4. 输出异常：确认格式控制符与实参类型匹配；
5. 实验提交：保留能复现问题的最小代码和测试输入。
