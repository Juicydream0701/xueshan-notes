# 大学物理（甲）Ⅱ：电磁、波动与近代物理

大学物理Ⅱ的知识看似分散，实际上可以用“场—波—量子”串起来。电磁学建立场的语言，波动光学研究相位和叠加，近代物理再解释微观尺度下能量和动量的离散性。

## 1. 静电场与电势

电场强度是单位正电荷所受力，电势是单位电荷的势能。点电荷场满足库仑定律，连续电荷分布要用积分叠加。高对称性问题可用高斯定律，但必须先判断高斯面上场强是否恒定或通量是否容易计算。

电势差沿路径积分得到。静电场保守，因此闭合路径积分为零；电势为常数的等势面与电场线正交。导体静电平衡时内部场为零、表面为等势面，边界条件是导体题的检查重点。

## 2. 稳恒电流与磁场

电流密度、欧姆定律和基尔霍夫定律把微观载流子运动连接到电路模型。磁场对运动电荷的作用力为洛伦兹力，方向由右手定则确定。长直导线、圆环和螺线管的磁场可由安培环路定律或毕奥—萨伐尔定律得到。

带电粒子在匀强磁场中作圆周或螺旋运动，半径和回旋频率分别由动量、速度和电荷决定。计算前先分解速度的平行和垂直分量，不能把总速度直接代入圆周半径。

## 3. 电磁感应与交流电

法拉第定律说明感应电动势由磁通量变化率决定，楞次定律给出方向。运动导体切割磁感线时，先判断有效长度和速度方向，再使用 $\mathcal E=Blv$。交流电路中相量法把微分关系转成复数代数关系，阻抗、功率因数和谐振条件要统一使用有效值。

## 4. 麦克斯韦方程与电磁波

麦克斯韦方程把电场、磁场、电荷和电流统一起来。位移电流项解释了随时间变化的电场也能产生磁场。平面电磁波中 $\mathbf E$、$\mathbf B$ 和传播方向两两垂直，能流方向由坡印廷矢量决定。介质界面反射和折射要同时满足边界条件。

## 5. 波动光学

干涉要求相干光源，光程差决定明暗。双缝、薄膜和迈克尔逊干涉的区别主要在于光程差表达式和相位突变。衍射题先判断是单缝还是光栅，再使用暗纹条件或主极大条件。偏振片遵循马吕斯定律，起偏、检偏和旋光要区分。

## 6. 量子与原子物理

光电效应说明光子能量与频率有关，康普顿效应体现光子动量。德布罗意关系把粒子波长与动量联系起来。玻尔模型适用于氢样原子，能级跃迁对应光谱线；不确定性原理说明位置和动量不能同时任意精确。

## 题型地图：从场到波再到量子

| 模块 | 先写什么 | 典型检查 |

## 代表题：带电粒子的匀强磁场运动

速度分解为 $v_\parallel$ 与 $v_\perp$。洛伦兹力只改变垂直分量方向，因此

$$r=\frac{mv_\perp}{|q|B},\qquad \omega=\frac{|q|B}{m},\qquad T=\frac{2\pi m}{|q|B}.$$

平行分量保持匀速，轨迹是螺距 $p=v_\parallel T$ 的螺旋线。若题目给的是动能，先用 $K=mv^2/2$ 求速度，再分解；若速度接近光速，不能继续使用经典动量。

## 代表题：电磁感应方向

先给回路法向和磁通量正号，再写 $\mathcal E=-d\Phi_B/dt$。负号表示感应电流产生的磁场反抗磁通量变化，不是“电动势为负就把答案改成正”。若磁场增大，感应磁场方向与原磁场相反；若面积减小，则先判断磁通量的实际变化再定方向。

## 波动光学的画图顺序

画入射光、反射光、折射光及法线，标出光程差；再根据反射介质折射率变化判断是否多一个 $\pi$ 相位。双缝干涉用 $\Delta=d\sin\theta\approx dx/L$，单缝暗纹用 $a\sin\theta=m\lambda$，光栅主极大用 $d\sin\theta=m\lambda$；三者的物理条件不同，不能只看公式相似。

## 量子题的三个守恒量

光电效应用 $h\nu=W_0+K_{\max}$，康普顿散射同时守恒能量和动量，氢样原子跃迁用

$$E_n=-\frac{13.6\,Z^2}{n^2}\ \mathrm{eV}.$$

先判断题目给的是频率、波长还是光子能量，再统一单位。能级跃迁满足 $h\nu=|E_{n_2}-E_{n_1}|$，发射与吸收的方向要结合能级图说明。
