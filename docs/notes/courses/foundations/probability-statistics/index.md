# 概率论与数理统计

## 这门课解决什么问题？

概率论描述随机现象，数理统计则从有限数据反推总体规律。实验测量、信号噪声、模型误差和数模预测，都需要先说清楚“随机量是什么、信息来自哪里、结论有多确定”。

## 学习主线

- 随机事件与概率：建立样本空间、条件概率和独立性的语言；
- 一维与多维随机变量：能从分布、密度和分布函数之间切换；
- 数字特征与极限定理：理解期望、方差、协方差，以及大数定律和中心极限定理；
- 抽样分布与参数估计：区分点估计、区间估计和估计量的性质；
- 假设检验：写出原假设、统计量、拒绝域和结论，避免只看 p 值。

## 做题和做实验都要检查

1. 随机变量的取值范围和分布是否写完整？
2. 使用的独立性、正态性或大样本条件是否成立？
3. 最后的结论是在样本层面，还是已经推广到总体？

## 和专业课的连接

信号分析中的噪声、电气实验中的测量误差、AI 模型的验证集，都可以用概率统计表达。学会报告不确定性，比只给一个平均值更接近真实工程。
