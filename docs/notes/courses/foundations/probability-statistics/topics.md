# 概率论与数理统计：专题笔记

## 专题一：事件、条件概率与独立性

先写样本空间，再定义事件。条件概率 $P(A|B)=P(AB)/P(B)$ 体现“信息改变了样本空间”。全概率公式把复杂事件按互斥完备事件分解，贝叶斯公式则把结果概率反推原因概率。独立性要求 $P(AB)=P(A)P(B)$，比“不相容”弱且完全不同。

## 专题二：随机变量与分布

离散变量用概率质量函数，连续变量用密度函数；分布函数 $F(x)=P(X\le x)$ 始终单调且右连续。求函数分布时先判断变换是否单调，再用区间概率或 Jacobian。二维变量要区分联合分布、边缘分布和条件分布。

## 专题三：数字特征与极限定理

期望描述中心，方差描述波动，协方差描述线性相关。相关系数为零不代表独立，只有在联合正态等特殊条件下才能进一步判断。大数定律说明样本均值趋近总体均值，中心极限定理说明标准化和近似正态的条件。

## 专题四：抽样分布与估计

点估计要比较无偏性、有效性和一致性；区间估计要写置信水平和统计量分布。正态总体均值、方差，以及大样本均值的区间形式不同，不能只看公式外形。置信区间是随机区间覆盖固定参数的长期比例，不是参数“落在区间内的概率”。

## 专题五：假设检验与回归

检验流程是提出 $H_0/H_1$、选统计量、确定拒绝域、计算样本值、给出结论。显著性水平控制第一类错误，不能把“不拒绝 $H_0$”说成“证明 $H_0$ 正确”。线性回归中先检查残差、独立性和方差齐性，再解释系数和预测区间。
