# 常微分方程

## 这门课解决什么问题？

当一个系统的变化率由当前状态决定，就可以尝试用常微分方程描述。电路充放电、机械振动、控制系统和人口模型，都依赖同一套“建模—求解—解释”流程。

## 方法选择表

| 看到的结构 | 先尝试的方法 |
| --- | --- |
| 一阶方程可以分离变量 | 分离变量并处理初值 |
| 一阶线性方程 | 积分因子法 |
| 二阶常系数线性方程 | 特征根法，注意重根和共轭复根 |
| 非齐次线性方程 | 待定系数法或常数变易法 |
| 多个变量互相耦合 | 写成一阶方程组，再看矩阵或消元 |

## 最容易混淆的地方

- 通解、特解和满足初值的解不是一回事；
- 特征根只解决齐次部分，非齐次项还需要补一个特解；
- 计算出解以后，要代回原方程和初始条件检查；
- 形式相同的方程，初始条件不同，物理含义可能完全不同。

## 和专业课的连接

电路暂态、信号系统和控制理论都在使用微分方程。复习时不要停在公式分类，试着把一个 RC 或 RLC 电路写成状态方程，再观察解的衰减和振荡。
