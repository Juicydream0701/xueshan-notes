# 常微分方程

## 课程内容

当一个系统的变化率由当前状态决定，就可以尝试用常微分方程描述。电路充放电、机械振动、控制系统和人口模型，都依赖同一套“建模—求解—解释”流程。

## 方法选择表

| 看到的结构 | 先尝试的方法 |
| --- | --- |
| 一阶方程可以分离变量 | 分离变量并处理初值 |
| 一阶线性方程 | 积分因子法 |
| 二阶常系数线性方程 | 特征根法，注意重根和共轭复根 |
| 非齐次线性方程 | 待定系数法或常数变易法 |
| 多个变量互相耦合 | 写成一阶方程组，再看矩阵或消元 |

## 最容易混淆的地方

- 通解、特解和满足初值的解不是一回事；
- 特征根只解决齐次部分，非齐次项还需要补一个特解；
- 计算出解以后，要代回原方程和初始条件检查；
- 形式相同的方程，初始条件不同，物理含义可能完全不同。

## 相关专业课程

电路暂态、信号系统和控制理论都在使用微分方程。复习时不要停在公式分类，试着把一个 RC 或 RLC 电路写成状态方程，再观察解的衰减和振荡。

## 三条必须熟练的解题主线

### 1. 一阶方程：识别结构比背公式重要

分离变量的前提是能把 (x) 与 (y) 的函数分别放到等号两边；积分后要补回常数并结合初值确定它。对一阶线性方程

$$
y'+p(x)y=q(x),
$$

积分因子取 \(\mu(x)=e^{\int p(x)\,dx}\)，使左侧变为 \((\mu y)'\)。如果题目给的是隐式关系或含参数曲线，先判断能否把它改写为显式的一阶方程，再决定是否需要讨论定义域和奇解。

### 2. 二阶方程：齐次解、特解、初值三步分开

常系数齐次方程的特征根决定解的形式：实根对应指数项，重根要乘以 (x)，共轭复根对应指数衰减（或增长）乘正弦余弦。非齐次项的特解不能与齐次解重复；当待定形式与齐次解相撞时，需要乘以足够次方的 (x)。

解出通解后再代入初值，能避免把常数混在求导过程中。对受迫振动，特别要区分暂态项和稳态项：齐次项的衰减依赖阻尼和系统稳定性，并非自动成立；稳定有阻尼系统中可把衰减项与受迫稳态项分开。无阻尼共振时可出现随时间增长的项，此时不存在有界的周期稳态。

### 3. 方程组与稳定性：把解写成矩阵指数

一阶线性系统可写成

$$
\mathbf{x}'=A\mathbf{x}+\mathbf{f}(t),\qquad
\mathbf{x}(t)=e^{At}\mathbf{x}(0)+\int_0^t e^{A(t-s)}\mathbf{f}(s)\,ds.
$$

当 (A) 可对角化时，矩阵指数可由特征值快速计算；不可对角化时仍可通过 Jordan 形式或级数定义处理。连续时间系统的零输入稳定性与特征值实部有关：所有特征值实部为负时渐近稳定，存在正实部时不稳定，纯虚根还需要进一步检查重数和输入。

## 建模、求解、验算模板

1. **建模**：选状态变量，写出守恒定律或受力方程，标注参数单位。
2. **化标准形**：整理为显式一阶方程、标准二阶方程或矩阵方程。
3. **求解**：先求齐次部分，再处理输入和边界/初值。
4. **验算**：代回微分方程、初值和极限情形；检查单位是否一致。
5. **解释**：说明时间常数、稳态值、振荡频率或稳定性，而不只给出公式。

!!! tip "与电路复习联动"
    对 RC 电路先写 \(C\,dv/dt+i_R=0\)，再用 \(i_R=v/R\) 得到一阶方程。这样能清楚看到时间常数 \(\tau=RC\) 的来源，也能避免直接套暂态公式时漏掉初始条件。
