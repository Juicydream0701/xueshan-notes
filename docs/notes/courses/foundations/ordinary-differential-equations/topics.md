# 常微分方程：专题笔记

## 专题一：一阶方程的识别

可分离方程写成 $y'=g(x)h(y)$，在 $h(y)\ne0$ 的区间内把 $dy/h(y)$ 与 $g(x)dx$ 分到两边后积分，并根据初值选常数；$h(y)=0$ 对应的常值解必须另外检查，不能在除法中丢掉。一阶线性方程 $y'+p(x)y=q(x)$ 的积分因子为 $\mu=e^{\int p(x)dx}$，乘上后左边成为 $(\mu y)'$。

若方程是齐次型 $y'=F(y/x)$，令 $y=vx$；若是 Bernoulli 方程 $y'+py=qy^n$，可令 $z=y^{1-n}$。代换前要记录 $y=0$ 是否被遗漏。

## 专题二：二阶常系数方程

齐次方程 $ay''+by'+cy=0$ 的特征方程为 $ar^2+br+c=0$。两个实根给出指数叠加，重根给出 $(C_1+C_2x)e^{rx}$，共轭复根 $\alpha\pm i\beta$ 给出 $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$。

非齐次项用待定系数法时，先看右端类型，再判断是否与齐次解共振；共振就乘以足够高次的 $x$。常数变易法适合右端复杂、系数不恒定的情况。

## 专题三：方程组与矩阵指数

一阶系统写作 $\mathbf x'=A\mathbf x+\mathbf f(t)$。齐次解由 $e^{At}$ 给出，若 $A=PDP^{-1}$，则 $e^{At}=Pe^{Dt}P^{-1}$。特征值实部决定稳定性和衰减/增长，复部决定振荡频率。

## 专题四：拉普拉斯变换解初值问题

用 $\mathcal L\{y'\}=sY-y(0)$ 把微分方程转成 $Y(s)$ 的代数式，再做部分分式和逆变换。初值必须在变换阶段完整代入；含阶跃或冲激时要使用移位性质。结果应同时检查初值和终值趋势。

## 专题五：模型解释与数值方法

RC 电路的时间常数决定指数衰减速度，二阶振子由阻尼比区分欠阻尼、临界阻尼和过阻尼。无法得到初等解时，可用欧拉、改进欧拉或 Runge–Kutta 离散化；步长越小不一定总是越好，还要关注稳定性和累计误差。

## 易错点与资料

- 通解、特解和满足初值的解要分开写；
- 共振判断要对照齐次解频率；
- 矩阵解要统一列向量约定；
- 数值结果要与解析解的极限趋势比较。
