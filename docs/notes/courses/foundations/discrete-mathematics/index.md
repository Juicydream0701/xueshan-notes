# 离散数学

## 课程内容

离散数学研究可以逐个枚举、判断或组合的结构。集合、关系、函数、图、树和逻辑，既是算法的基础，也是数字电路、通信协议和计算机系统的共同语言。

## 知识结构

1. 集合、关系和函数：先把对象、对应关系和运算写清楚。
2. 初等数论：掌握整除、同余和模运算的基本推理。
3. 图与树：区分连通、欧拉、哈密顿、生成树和最短路径等概念。
4. 组合结构：理解匹配、覆盖、独立集和着色的关系。
5. 命题逻辑与一阶逻辑：练习等价变形、推理链和量词作用域。

## 定义、例子与证明

- 每个定义都配一个满足条件和一个不满足条件的例子；
- 图论题先画图，再决定使用度数、连通性还是路径结构；
- 逻辑题把自然语言翻译成符号，最后再翻译回自然语言检查；
- 证明题明确“已知—要证—关键构造—结论”四步。

## 相关专业课程

数字电子技术里的逻辑化简、微机中的指令与状态、通信中的编码和算法设计，都依赖离散结构。课程训练包括计算、证明与结构设计。
