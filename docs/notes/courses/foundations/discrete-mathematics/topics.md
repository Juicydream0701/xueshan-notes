# 离散数学：专题笔记

## 专题一：集合、关系与函数

集合运算是后续证明的语言。关系的自反、对称、反对称和传递性质要逐条检查；等价关系把集合划分为互不相交的等价类，偏序关系则产生哈斯图。函数题先确认定义域、陪域和单射/满射，再讨论复合与逆函数。

## 专题二：数论与同余

整除、最大公因数和 Euclid 算法是同余运算的基础。模运算中只有当逆元存在时才能“约去”因子；解一次同余方程要先算 $\gcd(a,m)$，判断是否有解。中国剩余定理把互素模数下的多个条件合成一个解类。

## 专题三：图的结构

图论题先确定是无向图、有向图还是带权图。握手定理给出度数和为边数的两倍；连通、欧拉回路、哈密顿回路、二分图和树的定义不能混用。最短路使用 Dijkstra 要求非负权，负权边应考虑 Bellman–Ford；最小生成树常用 Kruskal 或 Prim。

## 专题四：树、平面图与匹配

树有 $n-1$ 条边且任意两点有唯一简单路径。根树可用于表达式、编码和搜索。平面图涉及 Euler 公式，匹配、覆盖、独立集和着色则把图结构连接到资源分配问题。做证明时先找反例，再决定是构造还是归纳。

## 专题五：命题与一阶逻辑

命题逻辑可用真值表、等价变形或归结证明。量词的作用域和否定规则是难点：$\neg\forall xP(x)$ 等价于 $\exists x\neg P(x)$。把自然语言拆成原子命题，再检查量词顺序，通常比直接凭语感判断可靠。
