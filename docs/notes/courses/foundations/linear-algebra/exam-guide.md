# 线性代数（甲）：从计算题到证明题

线性代数复习要把“算出结果”和“解释结构”放在一起。每道题先判断对象是方程组、线性映射、特征值还是二次型，再选择消元、换基、对角化或正定性判定。

## 1. 矩阵与初等变换

矩阵乘法的维数必须先检查。初等行变换保持方程组解集，但一般不保持特征值；相似变换保持特征值、迹和行列式。求逆矩阵可用增广矩阵 ([A\mid I]) 做行变换，若左侧不能化成 (I)，则矩阵不可逆。

行列式计算优先利用三类性质：交换两行变号、某行乘常数行列式乘同一常数、某行加另一行倍数不变。含参数题先找出使主元为零的特殊值，再分情况讨论秩。

## 2. 线性方程组与秩

对 (A\mathbf{x}=\mathbf{b})，比较 (r(A)) 和 (r([A\mid\mathbf b]))：

- 两秩不等：无解；
- 两秩相等且等于未知数个数：唯一解；
- 两秩相等且小于未知数个数：无穷多解，自由变量个数为 (n-r(A))。

齐次方程组一定有零解。若题目问基础解系，先消元找自由变量，再令自由变量逐个取单位值，得到线性无关的解向量。写完要检查向量个数是否等于 (n-r(A))。

## 3. 向量空间与线性映射

判断一组向量是否线性相关，可把向量作为列组成矩阵并求秩。基必须同时满足张成空间和线性无关。维数相同的有限维空间中，线性映射单射、满射和可逆彼此等价。

换基题最容易错在箭头方向。若 (P_{\mathcal B\leftarrow\mathcal E}) 表示把标准坐标转成基 \(\mathcal B\) 坐标，就要明确矩阵乘在坐标向量的哪一侧，并用一个简单基向量作反向验证。

## 4. 特征值、特征向量与相似对角化

特征值来自

$$
\det(\lambda I-A)=0.
$$

每个特征值的几何重数不超过代数重数。矩阵可相似对角化，当且仅当所有特征子空间维数之和为 (n)。实对称矩阵一定能正交对角化，这一结论在二次型、模态分解和控制系统中反复出现。

若 (A=PDP^{-1})，则 (A^k=PD^kP^{-1})，矩阵指数也可化为 (e^{At}=Pe^{Dt}P^{-1})。求高次幂时先判断是否可对角化，不能只凭特征值互异的局部情况下结论。

## 5. 二次型与正定性

二次型 (q(\mathbf x)=\mathbf x^{\mathsf T}A\mathbf x) 只由 (A) 的对称部分决定。判断正定性常用三种方法：所有特征值为正、顺序主子式全为正、配方得到平方和。题目含参数时，主子式条件通常最直接，但要把每个不等式的范围交集写清。

正交变换可以把实对称矩阵化为对角形，几何上对应旋转坐标轴。化标准形时同时记录秩、正惯性指数和负惯性指数，避免只写最后的平方和而丢失分类信息。

## 6. 综合题模板

1. 写出矩阵或线性映射的对象和维数；
2. 先做秩、行列式或特征多项式的结构判断；
3. 再进行计算，保留参数分支；
4. 用维数、迹、行列式或特征值检查结果；
5. 若是证明题，明确使用的定理和前提。

常见错误包括：把行变换当成相似变换、忽略参数导致的秩变化、把特征值代数重数当作特征向量个数、换基矩阵方向写反。
