# 大学物理（甲）Ⅰ

## 课程内容

大学物理训练的是用守恒律、微分关系和模型近似描述自然过程。对电气和电子方向，力学提供建模习惯，振动与波连接信号，静电场则是电磁学和电路直觉的入口。

## 推荐回看顺序

1. 质点运动学与动力学：先会从运动规律写出速度、加速度和受力方程。
2. 动量、角动量与能量：遇到复杂过程优先寻找守恒量。
3. 刚体、振动与波：重点理解转动惯量、简谐运动和相位。
4. 气体动理论与热力学：区分微观统计描述和宏观状态量。
5. 静电场：从场强、电势和高斯定律建立电磁学语言。

## 解题检查

- 先画过程图，标出坐标、初始条件和方向；
- 先判断守恒关系，再决定是否需要逐项列式；
- 结果要检查量纲、极限情况和正负号；
- 振动与波题要保留相位信息，不能只看振幅。

## 相关专业课程

信号分析中的正弦信号、工程电磁场中的场量、电路暂态中的指数变化，都可以在物理课的模型中找到原型。复习时建议把公式写成“适用条件 + 物理意义”。

## 逐章解题路线

### 力学：从受力图到守恒律

质点题先选惯性参考系，画受力图并规定正方向。若约束力未知，优先列牛顿第二定律；若只求速度或位移，先检查机械能是否守恒。碰撞题分别写动量守恒和能量关系，不能把完全弹性条件误用于一般碰撞。

### 振动与波：相位比公式更关键

简谐运动可写成 (x=A\cos(\omega t+\varphi))。给出初始位移和速度时，先代入 (t=0) 求 (A,\varphi)，再由 (v=-A\omega\sin(\omega t+\varphi)) 检查相位。波动题要区分传播方向：(f(x-vt)) 向 (+x) 传播，(f(x+vt)) 向 (-x) 传播。

### 热学：状态方程与过程条件

理想气体题先写状态方程 (pV=nRT)，再根据等温、等压、等容或绝热条件简化。热力学第一定律的正负号必须在开头声明，例如取系统吸热为正时 (Q=\Delta U+W)，其中 (W) 为系统对外做功。

### 静电场：对称性决定方法

球对称、柱对称和平面对称优先考虑高斯定律；不具备对称性时，使用积分定义。电势是标量，叠加通常比直接叠加矢量场更简洁。跨过导体表面时要检查切向电场和电势连续性条件。

### 电磁感应与波动光学

法拉第定律写成 (\mathcal E=-d\Phi_B/dt)，负号体现楞次定律。判断方向时先选回路正向，再根据磁通量变化判断感应电流。干涉和衍射题先写光程差，再根据相长/相消条件判断条纹位置。
