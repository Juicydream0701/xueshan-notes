## 使用方法

- 第一次学习：阅读知识结构与常见问题，再打开 PDF。
- 考前回顾：只看“复习要点”和资料中的例题，不从头翻整套教材。
- 做项目：回到页面底部的“相关专业课程”，把基础概念落到电路、信号、微机或 AI 实验中。

!!! note "资料范围"
    公开主站只保存能帮助理解和复习的少量资料。原始课程文件仍在本地课程文件夹中，后续如果发现某份资料需要长期保留，再单独精选加入。
