# 基础课与数学工具

专业课像一座山，数学、物理、编程和数据方法就是登山时的工具。这一组页面把四个学期的课程资料压缩成少量可复习的路径：先说明课程解决什么问题，再给出适合回看的顺序，最后提供一份精选文件。

| 课程 | 你会得到什么 |
| --- | --- |
| [C 程序设计基础及实验](c-programming/index.md) | 从语法走到指针、调试和文件操作 |
| [线性代数（甲）](linear-algebra/index.md) | 用矩阵语言理解网络、信号和数据 |
| [大学物理（甲）Ⅰ](college-physics/index.md) | 把力学、振动、热学和静电场连起来 |
| [常微分方程](ordinary-differential-equations/index.md) | 建立动态系统的方程和解题流程 |
| [人工智能基础（A）](ai-foundations/index.md) | 了解机器学习、深度网络与大模型的关系 |
| [概率论与数理统计](probability-statistics/index.md) | 用概率语言描述数据和不确定性 |
| [离散数学](discrete-mathematics/index.md) | 训练图、树、关系和逻辑推理 |

## 使用方法

- 第一次学习：先读页面中的“主线”和“容易卡住的地方”，再打开 PDF。
- 考前回顾：只看“最小复习清单”和资料中的例题，不从头翻整套教材。
- 做项目：回到页面底部的“和专业课的连接”，把基础概念落到电路、信号、微机或 AI 实验中。

!!! tip "这组资料的原则"
    公开主站只保存能帮助理解和复习的少量资料。原始课程文件仍在本地课程文件夹中，后续如果发现某份资料需要长期保留，再单独精选加入。
