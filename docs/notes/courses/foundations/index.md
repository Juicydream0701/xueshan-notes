## 使用方法

- 第一次学习：阅读知识结构与常见问题，再打开 PDF。
- 考前回顾：只看“复习要点”和资料中的例题，不从头翻整套教材。
- 做项目：回到页面底部的“相关专业课程”，把基础概念落到电路、信号、微机或 AI 实验中。

!!! note "资料范围"
    公开主站只保存能帮助理解和复习的少量资料。原始课程文件仍在本地课程文件夹中，后续如果发现某份资料需要长期保留，再单独精选加入。

## 课程之间怎么衔接

基础课不是一组互相孤立的“公式册”。建议按下面的链条回看：

| 学习目标 | 先修课程 | 需要留下的可检查产物 | 后续用途 |
| --- | --- | --- | --- |
| 描述变化率与累积量 | 微积分 | 极限条件、导数/积分的适用范围、误差估计 | 微分方程、信号分析、电路暂态 |
| 处理状态和结构 | 线性代数、离散数学 | 秩、基、图/树、逻辑证明 | 微机、通信、控制与算法 |
| 处理动态过程 | 常微分方程、大学物理 | 初值、边界、稳定性和量纲检查 | 电网络、控制、半导体物理 |
| 处理不确定数据 | 概率统计 | 随机变量、估计、检验和残差诊断 | AI 实验、测量与建模 |
| 实现可复现计算 | C 程序设计、AI 基础 | 输入输出约定、基线、测试样例和日志 | 工程实验、数据处理 |

## 每门课都用同一张复习卡

1. **范围**：这一门课解决什么问题，输入和输出是什么？
2. **条件**：定理、公式或算法在什么条件下成立？
3. **最小例题**：用一个能手算的例子验证定义和符号。
4. **反例**：记录一个“看起来相似但不能套用”的情况。
5. **资料**：把对应讲义或复习 PDF 放在专题后面，阅读后注明页码。
6. **迁移**：写一句它在电路、信号、微机、AI 或生活数据中的用法。

这样整理后，页面既能用于第一次学习，也能在考前快速定位“条件—方法—检查”三件事。
