# 工程图学

工程图学把三维对象转换为可制造、可检验的二维表达。复习时不要把它当成“背符号”的课程，而要沿着 **对象分析 → 投影选择 → 图线表达 → 尺寸约束 → 工艺检查** 的链条练习。下面的路线按作图题和读图题组织，保留了课程资料中最适合公开复习的讲义入口。

## 一、先建立投影坐标系

正投影的核心是投影线彼此平行且垂直于投影面。对一个空间点 \(P(x,y,z)\)，在三个互相垂直的投影面上，可以分别观察到它的两个坐标组合。画图前先确认：

1. 选择主视方向，使主要结构和尺寸尽可能显露；
2. 用主视图确定高、宽，用俯视图确定深度，用左视图交叉校验；
3. 同一条棱在相邻视图中的投影必须满足“长对正、高平齐、宽相等”；
4. 不可见轮廓用虚线表示，重合或难以辨认时优先保留结构逻辑。

三视图不是三个独立的草图，而是同一空间对象的约束系统。若主视图中某条线段长度为 \(l\)，则它在俯视图或左视图中的对应投影应与同一方向尺寸一致。遇到“看起来差不多”的答案，先回到投影关系检查，而不是直接修改局部线条。

## 二、点、线、面的相对位置

点在线上、线在面上等从属关系，依赖投影中的重合。判断一条空间直线是否为特殊位置线，可以检查它在某个投影面上的投影是否退化为点或保持真实长度：

- 平行于投影面时，该投影显示真实长度；
- 垂直于投影面时，该投影退化为一点；
- 倾斜于投影面时，投影长度满足 \(l' = l\cos\theta\)，其中 \(\theta\) 是直线与投影面的夹角。

作辅助线时，先写清楚要得到的几何量：真实长度、点到面的距离，还是两平面的夹角。辅助投影面只解决一个主要问题，画完后应删除无关的构造线，避免答案图变成“辅助线堆积”。

## 三、截切体与相贯体

截切体的作图顺序是“找截交线上的控制点 → 分别投影 → 光滑连接 → 判断可见性”。控制点通常包括：截平面与棱线的交点、轮廓极值点以及转折处的特征点。相贯体则要同时满足两个曲面的方程，常用辅助平面或素线法求交点。

考试中最容易失分的地方有三个：

1. 只画出截交线的一部分，没有补齐被截断的原轮廓；
2. 把可见性判断交给直觉，没有沿投影方向逐段比较遮挡关系；
3. 光滑曲线没有通过全部控制点，导致相贯线出现尖角或断裂。

## 四、组合体读图与尺寸标注

读组合体时，先按基本体拆分，再按“加、减、相切、相贯”关系复原。标注尺寸应服务于加工和检验：

- 定形尺寸说明某个基本体的大小；
- 定位尺寸说明基本体相对基准的位置；
- 总体尺寸用于校验，不能与局部尺寸重复形成过约束。

基准应尽量选用设计基准或加工基准。线性尺寸的单位通常为毫米，图中统一后不必逐项重复写单位。直径使用 φ，半径使用 R，球面直径和球面半径应使用相应前缀。尺寸线、尺寸界线和箭头不能与轮廓线混淆。

## 五、剖视图与断面图

当内部结构复杂、虚线过多时，用剖视图表达更清楚。剖切位置由剖切符号标出，剖面区域画出与材料相关的剖面线。剖面线间距应均匀，方向可在相邻零件之间错开，以区分装配关系。

全剖适合对称或内部结构集中的零件；半剖适合具有对称面的零件；局部剖用于只需揭示某个内部细节的场景。剖切到的标准件、轴、键等通常按规定不画剖面线，避免把装配结构误判为实体材料。

## 六、零件图的工艺检查

零件图应同时回答“是什么、做多大、怎么加工、如何检验”。拿到一张图可按以下顺序复核：

1. 看标题栏，确认材料、比例、投影法和图号；
2. 看主视图及剖视图，确定结构与加工表面；
3. 沿基准逐项检查尺寸链，确认没有遗漏和矛盾；
4. 检查表面粗糙度、尺寸公差、形位公差和技术要求；
5. 思考刀具能否进入、测量基准是否可达、装配是否会干涉。

尺寸链中若存在闭环，基本关系可以写成

$$
 A_0 = \sum A_i^{+} - \sum A_j^{-},
$$

其中 \(A_0\) 是封闭环，带正号和负号的尺寸分别表示与封闭环同向和反向的组成环。考试题中先判断方向，再做极限尺寸或公差计算。
