# 计算机网络与通信：专题笔记

## 专题一：分层模型与物理链路

OSI 七层和 TCP/IP 分层的关键不是背名称，而是理解封装：应用数据逐层添加首部，接收端逐层去除。物理层关心比特、带宽和信号；数据链路层负责相邻节点的帧传输；网络层负责跨网络寻址和转发；传输层为进程提供端到端服务。

带宽、传播时延和传输时延要区分。传输时延近似为 $L/R$，传播时延为 $d/v$；窗口协议的吞吐量还受往返时延约束。题目给链路长度、速率和帧长时，先列这几个量再作比较。

## 专题二：数据链路、交换与 VLAN

以太网帧包含目的/源 MAC、类型或长度、数据和校验字段。交换机通过自学习表把帧转发到对应端口，未知目的或广播帧会泛洪。生成树协议用于避免二层环路，VLAN 则用标签把一个物理交换网络划分为多个逻辑广播域。

可靠链路常用 CRC 检错；滑动窗口协议用确认、序号和超时实现流水线。停等协议简单但带宽利用率低，回退 N 帧会重传一段窗口，选择重传只重传丢失帧。作图时要标发送窗口、确认号和超时点。

## 专题三：IP 寻址、路由与 IPv6

IPv4 前缀 `/n` 表示前 n 位为网络号，主机数通常为 $2^{32-n}-2$（需考虑特殊子网）。最长前缀匹配决定路由表中优先使用哪条路径。子网划分题先把地址写成二进制，再根据主机数向上取整分配主机位。

路由算法中，距离向量基于 Bellman-Ford，链路状态基于全网拓扑和 Dijkstra。NAT 改写地址和端口缓解地址不足，但会影响端到端可达性。IPv6 使用更长地址、邻居发现和无状态自动配置，题目要注意压缩书写规则。

## 专题四：TCP/UDP 与拥塞控制

UDP 无连接、开销小，可靠性由应用自行实现；TCP 通过三次握手建立连接、序号与确认保证可靠有序传输。滑动窗口由接收窗口和拥塞窗口共同限制，实际可发送数据量取两者较小值。

拥塞控制包含慢启动、拥塞避免、快速重传和快速恢复。发生超时通常把拥塞窗口降到较小值，收到重复 ACK 则可能触发快速重传。计算窗口变化时按 RTT 分段画时间轴，明确每一轮的阈值和丢包事件。

## 专题五：DNS、HTTP 与网络安全

DNS 用层次化域名解析把名称映射为 IP，递归解析器可能缓存结果，TTL 决定缓存有效时间。HTTP 是请求—响应协议，持久连接、缓存和状态码决定应用性能。HTTPS 在 HTTP 之下加入 TLS，使用证书验证身份并协商会话密钥。

安全题可按机密性、完整性、身份认证和可用性四个目标分类。对称加密适合大量数据，非对称加密适合密钥交换和签名，哈希用于完整性校验。常见失分点是把编码、加密和哈希混为一谈，或忽略证书链和随机数。
