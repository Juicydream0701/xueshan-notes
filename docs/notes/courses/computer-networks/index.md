# 计算机网络与通信

本课程可以用“分层、寻址、转发、可靠性、应用”五条线复习。每一题先判断处在哪一层，再写协议状态、地址格式和时序，避免把链路层、网络层和传输层的功能混在一起。

## 五个专题

1. [分层模型与物理链路](topics.md)
2. [数据链路、交换与 VLAN](topics.md)
3. [IP 寻址、路由与 IPv6](topics.md)
4. [TCP/UDP 与拥塞控制](topics.md)
5. [DNS、HTTP 与网络安全](topics.md)
