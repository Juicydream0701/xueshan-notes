# 宽带无线通信技术设计与实践

这门课适合做成项目型入口：从需求、链路预算和信道模型开始，经过调制、同步、编码和天线/射频实现，最后用误码率、吞吐量和覆盖范围验证系统。当前课程资料以项目文件为主，因此先保留一份轻量路线，后续再补充公开讲义。

## 五个实践专题

1. **需求与链路预算**：确定频段、带宽、发射功率、接收灵敏度和链路余量。自由空间损耗可写为 $L_p=32.45+20\log_{10}f_{MHz}+20\log_{10}d_{km}$。
2. **调制与同步**：比较 PSK、QAM、OFDM 的频谱效率和抗噪声能力，设计载波、符号和帧同步。
3. **信道与均衡**：用瑞利/莱斯模型描述多径衰落，以导频估计信道并用均衡器抑制码间串扰。
4. **编码与链路自适应**：通过卷积码、LDPC 或交织降低误码率，根据 SNR 选择调制阶数和编码率。
5. **测试与复现**：固定随机种子、采样率和指标，记录 BER、EVM、吞吐量与 CPU 占用，确保仿真可复现。
