# 定时器与计数器

80C51 的定时器/计数器本质上是加一计数器。选择“定时”时，计数脉冲来自内部时钟；选择“计数”时，脉冲来自 T0/T1 外部引脚。

## 控制寄存器

| 寄存器 | 作用 |
| --- | --- |
| `TMOD` | 分别设置 T1、T0 的门控 GATE、定时/计数选择 C/T、工作方式 M1/M0；不可位寻址 |
| `TCON` | `TR0/TR1` 启停计数器；`TF0/TF1` 表示溢出；还包含外部中断触发和请求位 |
| `TH0/TL0`、`TH1/TL1` | T0/T1 的计数高、低字节 |
| `T2CON`、`TH2/TL2` | 80C52 等型号的 T2 控制和计数寄存器 |

`GATE=0` 时用 TRx 控制运行；`GATE=1` 时还要求对应 INTx 引脚有效。`C/T=0` 是定时，`C/T=1` 是外部计数。

## T0/T1 的工作方式

| M1:M0 | 结构 | 典型场景 |
| --- | --- | --- |
| `00` | 方式 0，13 位计数 | 兼容旧系统，容量较小 |
| `01` | 方式 1，16 位计数 | 较长单次定时或计数 |
| `10` | 方式 2，8 位自动重装 | 稳定的周期中断、串口波特率发生器 |
| `11` | 方式 3，拆分 T0 | TL0/TH0 分别工作；T1 的资源用途受限 |

不同 8051 派生芯片对定时器时钟和扩展方式可能不同；先查芯片数据手册，再套用经典 12T 公式。

## 初值计算

经典 12T 内核的内部定时器计数间隔为：

`Ttick = 12 / fosc`

需要计数 `N = t / Ttick` 次时，16 位方式 1 初值为：

`initial = 65536 - N`

再拆分为 `THx = initial >> 8`、`TLx = initial & 0xFF`。13 位方式 0 的模数为 8192，8 位方式 2 的模数为 256。整数取整、启动延迟、中断响应和重装指令会带来误差；精确波形要把软件延迟也算进去。

例：晶振 12 MHz 时，经典 12T 机器周期为 1 μs。方式 1 计 1000 次对应 1 ms，初值为 `FC18H`。若每次溢出翻转一次输出引脚，则输出完整周期约为 2 ms。

## 周期中断与自动重装

方式 1 溢出后软件通常需要重写 THx/TLx；服务程序的重装时刻会影响周期精度。方式 2 由 TLx 从 THx 自动重装，适合固定节拍。将 T0 配置为方式 3 后，TL0 和 TH0 可以拆成两个 8 位计数部分，但会占用其他控制资源。

## 外部事件计数

- T0 输入引脚为 P3.4，T1 为 P3.5。
- 计数器检测外部输入的高到低跳变；输入频率受采样时序限制。
- `GATE` 可把 INTx 电平用作计数器的运行门控，适合测量脉冲宽度。
- 脉冲宽度超过一次溢出范围时，软件还需累计溢出次数。

## 初始化核对表

1. 先确定目标是定时还是外部计数，以及选 T0 还是 T1。
2. 计算每次计数周期和目标计数值，检查是否超出当前位宽。
3. 配置 TMOD 的对应四位，加载初值。
4. 若使用中断，设置 TFx/ETx/EA 的处理方式；配置好服务向量。
5. 最后启动 TRx，并用示波器或逻辑分析仪核对实际周期。
