# 接口扩展

扩展接口时先画出信号路径：地址由谁给出、数据如何传输、哪个信号选中器件、读写由什么控制。再确定地址译码、电气连接和软件访问方式。

## 80C51 外部并行总线

- P0 复用为 AD0-AD7，先输出低位地址，再传输数据；ALE 控制 74LS373 等锁存器保持低位地址。
- P2 输出高位地址 A8-A15。
- `/PSEN` 用于外部程序存储器取指；`/RD`、`/WR` 用于外部数据存储器读写。
- 外部程序与数据空间使用相同地址线但不同控制信号，因此逻辑空间独立。
- 完全译码使用全部相关高位地址选择器件；部分译码电路较简单，但可能产生多个地址别名。

外扩前计算地址范围和芯片容量，检查片选条件互斥、地址线数量正确，以及数据总线方向与读写时序一致。

## 并行 I/O 扩展

简单输入/输出锁存器可分别用于读取外部状态或保持输出。可编程接口芯片（例如 8155/8255）增加端口和控制模式，但需要先写控制字，再按芯片地址图访问端口。

典型检查：

1. 片选地址是否唯一，控制字地址与端口地址是否分清。
2. 输入缓冲器输出是否只在读周期驱动总线。
3. 输出锁存器是否在目标写周期锁存数据。
4. P0 上拉、锁存器 ALE 极性和 `/RD`、`/WR` 有效电平是否匹配。

## 键盘扫描与消抖

机械按键闭合和释放时会短暂抖动。硬件 RC/触发器或软件延时后二次确认都可消抖；软件消抖要兼顾响应速度与误触发率。

矩阵键盘通过逐行/逐列驱动并读取另一组引脚确定按键坐标。行扫描需要逐行输出有效电平，再读取列线；行列反转法通过两次方向相反的扫描确认行、列。多键同时按下可能产生鬼键，需按电路是否有隔离二极管决定支持范围。

## LED 与 LCD 显示

- 动态数码管显示把段码送到公共段线，再快速轮流选择位选；亮度由扫描频率和占空比共同影响。
- 段码表、位选极性和共阴/共阳类型要与硬件一致。
- 扫描程序通常由定时中断驱动，每次只刷新一位，避免主程序阻塞。
- LCD 控制器需要遵循命令/数据时序和忙标志规则；点阵显示还要确认字模的行列方向、位序和编码。

## 串行扩展总线

| 总线 | 主要信号 | 典型特点 |
| --- | --- | --- |
| SPI | SCK、MOSI、MISO、CS | 同步、通常全双工；每个从设备常需独立片选 |
| I²C | SDA、SCL | 两线共享总线，开漏/开集电极并上拉；含起始、地址、应答和停止 |
| 1-Wire | DQ | 单数据线，靠严格时序编码和复位/存在脉冲通信 |

协议软件应明确主从角色、时钟极性/相位（SPI）、地址和 ACK（I²C）、字节时序（1-Wire）、超时与错误恢复。不同芯片对地址格式和命令细节不同，应以器件数据手册为准。
