# 80C51 基础结构

## 系统由什么组成

单片机把 CPU、程序存储器、数据存储器、并行 I/O、定时器/计数器、中断控制器和串行接口集成在一颗芯片中。CPU 按程序计数器 PC 指向的地址取指、译码并执行；外部引脚负责供电、时钟、复位、并行总线和外设信号。

经典 MCS-51 采用分离的程序空间与数据空间。两者地址可以相同，但访问指令和控制信号不同：程序空间用于取指和常量表，数据空间用于运行期读写。

## 80C51 常用引脚

| 引脚 | 主要作用 | 使用时注意 |
| --- | --- | --- |
| P0.0-P0.7 | 通用 I/O；外扩时复用为 AD0-AD7 | 通用输出为开漏结构，需要外接上拉；总线低地址与数据分时复用 |
| P1.0-P1.7 | 通用 I/O | 传统 8051 上通常没有外部总线复用功能 |
| P2.0-P2.7 | 通用 I/O；外扩时输出 A8-A15 | 外部总线周期会使用 P2 输出高位地址 |
| P3.0-P3.7 | I/O 与第二功能复用 | RXD、TXD、INT0、INT1、T0、T1、`/WR`、`/RD` |
| ALE | 地址锁存允许 | 配合外部锁存器保存 P0 上的低位地址 |
| `/PSEN` | 外部程序存储器读选通 | 低电平有效；区别于外部数据存储器的 `/RD` |
| `/EA` | 程序空间选择 | 高电平允许使用片内程序存储器，低电平强制从外部程序空间取指 |
| RST | 复位输入 | 高电平有效；复位后 PC 指向 `0000H` |
| XTAL1/XTAL2 | 晶振或时钟输入 | 频率决定经典内核的机器周期与外设节拍 |

## 存储器地图

80C51 有三个逻辑地址空间。访问空间时要同时看地址和指令，不能只看地址数字。

| 空间 | 范围 | 典型用途与访问方式 |
| --- | --- | --- |
| 程序存储器 | `0000H-FFFFH`，最多 64 KB | 取指由 PC 控制；查表用 `MOVC`；片外读选通为 `/PSEN` |
| 片内数据 RAM | 8051 的低 128 B；8052 另有高 128 B | 工作变量、寄存器组、堆栈；使用 `MOV` 或寄存器间接寻址 |
| 特殊功能寄存器 SFR | 直接地址 `80H-FFH` | 控制端口、定时器、中断和串口；只能直接寻址 |
| 片外数据存储器 | `0000H-FFFFH`，最多 64 KB | 使用 `MOVX`；总线读写由 `/RD` 与 `/WR` 控制 |

80C52 的高 128 B 内部 RAM 与 SFR 地址范围重叠，但通过寻址方式区分：直接地址访问 SFR，寄存器间接地址访问高 RAM。普通 80C51 没有这片高 RAM。

### 片内低 128 B RAM

| 地址 | 用途 |
| --- | --- |
| `00H-1FH` | 四组工作寄存器，每组 `R0-R7`；由 PSW 中的 `RS1:RS0` 选择 |
| `20H-2FH` | 16 字节位寻址区，共 128 个可独立寻址的位 |
| `30H-7FH` | 通用 RAM，可放变量、缓冲区和堆栈 |

复位后 SP 初值为 `07H`。8051 堆栈向高地址增长，`PUSH` 或子程序调用先增加 SP，再写入数据。程序通常在初始化时把 SP 移到未被变量占用的 RAM 区。

## CPU 中常用寄存器

| 寄存器 | 位宽 | 用途 |
| --- | --- | --- |
| PC | 16 位 | 保存下一条将取出指令的程序地址；不是普通 SFR |
| DPTR | 16 位 | 外部数据地址或程序查表基址；由 DPH、DPL 构成 |
| SP | 8 位 | 指向片内 RAM 堆栈顶 |
| ACC / A | 8 位 | 算术、逻辑和数据传输的核心寄存器 |
| B | 8 位 | `MUL AB` 和 `DIV AB` 的第二操作数及结果寄存器 |
| PSW | 8 位 | 保存进位、辅助进位、工作组选择、溢出和奇偶标志 |

PSW 的常见位：`CY`（进位/借位）、`AC`（低半字节辅助进位）、`F0`（用户标志）、`RS1:RS0`（寄存器组）、`OV`（有符号溢出）、`P`（A 中 1 的奇偶性）。

## 并行 I/O 端口

P0-P3 共 32 根 I/O。P0 作为普通 I/O 时要考虑外接上拉；读端口作输入前先向锁存器写 1，释放引脚。P1/P2/P3 有内部上拉结构。P3 的第二功能由外设逻辑控制，使用对应功能时应避免同时把同一引脚当作普通输出。

## 时钟与工作方式

经典 12T 8051 一个机器周期包含 12 个振荡周期，因此 `Tmc = 12 / fosc`。当 `fosc = 12 MHz` 时，一个机器周期为 1 μs。具体指令可能需要不同机器周期；定时器、串口和外部总线的速度也取决于具体芯片实现。

复位后程序从 `0000H` 开始。空闲方式保留 RAM 和外设状态并停止 CPU 执行；掉电方式停止振荡器，适合低功耗，但可唤醒条件受芯片型号限制。实际设计要查所用器件的数据手册。
