# Cortex-M 与 STM32

Cortex-M3/M4 是面向微控制器的 32 位 ARM 内核。课程从 8051 转向 Cortex-M 时，概念仍可对应：寄存器、存储器映射、异常、中断、定时器、串口和 GPIO 都存在，但寄存器宽度、总线结构和配置方式不同。

## 内核与寄存器

- Cortex-M3/M4 执行 Thumb/Thumb-2 指令，使用 32 位寄存器和地址。
- `R0-R12` 为通用寄存器；`SP` 为堆栈指针，常见实现有 MSP 和 PSP；`LR` 保存返回信息，`PC` 指向程序流。
- xPSR 保存应用状态、执行状态和异常状态。
- 特殊寄存器包括中断屏蔽与控制状态寄存器；具体权限和字段要查处理器参考手册。
- 内核支持线程模式与处理模式、特权与非特权访问；异常处理由硬件向量机制支持。

Cortex-M 的堆栈通常向低地址增长。异常进入时硬件自动压入一组核心寄存器，异常返回通过专用异常返回值恢复现场；这与 8051 由软件保存 A、PSW 等寄存器的常见写法不同。

## 存储器映射与对齐

Cortex-M 使用统一的 4 GB 地址映射，把代码、SRAM、外设和系统控制空间放在不同地址区域。外设寄存器通过内存映射访问。地址是按字节编号的；32 位访问通常要求自然对齐，非对齐支持和异常行为取决于指令及具体芯片。

## 异常与 NVIC

NVIC 管理可屏蔽中断的使能、挂起、优先级和嵌套。设计外部中断时通常要完成 GPIO 输入配置、EXTI 触发边沿、NVIC 通道使能、优先级设置和中断服务函数。服务函数还必须清除外设或 EXTI 的请求标志，否则中断会重复触发。

与 8051 比较：8051 有固定向量和两级优先级；Cortex-M 的 NVIC 通道更多，并可配置优先级分组与嵌套。两者都需要让中断服务尽可能短，并安全地处理共享数据。

## STM32 外设初始化顺序

一个 GPIO 或外设功能通常按以下顺序配置：

1. 打开对应外设时钟。
2. 设置引脚模式、输出类型、速度、上下拉或复用功能。
3. 配置外设本身的分频、计数范围、数据格式或触发源。
4. 如需中断，配置外设中断源、清标志、配置 NVIC 并使能。
5. 启动外设并验证输入、输出或中断行为。

STM32F4 课程涉及的外设包括 GPIO、NVIC/EXTI、通用/高级定时器、PWM、USART、DMA、FSMC 和 ADC。DMA 可以在外设与内存之间搬运数据，减少 CPU 逐字节处理；ADC 把模拟输入转换为数字量，采样率和参考电压会影响结果。

## 8051 与 Cortex-M 对照

| 主题 | 80C51 | Cortex-M / STM32 |
| --- | --- | --- |
| 数据宽度 | 8 位累加器与寄存器 | 32 位通用寄存器 |
| 数据访问 | `MOV`、`MOVX`、`MOVC` 区分逻辑空间 | 内存映射访问 RAM 与外设寄存器 |
| I/O | P0-P3，部分引脚复用固定功能 | GPIO 可配置输入、输出、复用和模拟模式 |
| 中断控制 | IE/IP、固定向量、两级优先级 | 向量表与 NVIC，可配置通道优先级 |
| 定时 | T0/T1/T2 计数模式固定 | 多种通用/高级定时器和时钟源 |
| 开发方式 | 汇编或 C，直接配置 SFR | C、CMSIS、HAL/LL、CubeMX 等工具链 |

学习 Cortex-M 时不要把 8051 的 SFR 地址、机器周期或串口公式直接套用到 STM32。应先找芯片的参考手册、启动文件和工程时钟配置。
