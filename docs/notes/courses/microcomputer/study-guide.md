# 微机原理与应用：复习路线与综合题

微机原理既考概念边界，也考程序执行和硬件时序。建议至少分几轮学习，不要把所有时间押在考前背指令；爱班课程经验也建议预留数天系统复习，并结合智云课程和近年试题训练。

## 复习路线

### 第一轮：搭建结构图

把 8051 数据空间分成程序存储器、片内 RAM、SFR 和片外数据 RAM，记清分别由什么寻址与指令访问。然后梳理 CPU 寄存器、端口复用、总线信号和复位/时钟关系。不要把 `MOV`、`MOVX` 和 `MOVC` 混为同一空间访问。

### 第二轮：按题型手算程序

对指令题逐条记录操作数、寻址方式、结果、CY/AC/OV/P 变化及 PC 跳转。遇到 `CJNE`、`SUBB`、`DJNZ` 和相对转移时重点检查进位含义、无符号比较和跳转范围。多字节运算从低字节开始传递进位/借位。

### 第三轮：中断、定时与串口

每个外设都按同一模板整理：时钟源与模式 → 关键寄存器 → 中断/标志位 → 初始化顺序 → 服务程序 → 测试现象。定时器计算前先确认机器周期、定时器时钟和计数方式，再由目标时间推算计数初值；不同芯片可能不是经典 12T，必须以实验芯片资料为准。

串口题先明确波特率发生器、数据位、校验和停止位，再检查收发标志位的清除/置位条件。中断服务程序尽可能短，涉及共享数据时考虑原子性和现场保护。

### 第四轮：接口与综合设计

把键盘、显示、存储器扩展、ADC、PWM、串口和 Cortex-M 外设拆成可验证模块。先画数据流和引脚连接，再写寄存器配置，最后做模块测试。STM32 配置通常还需要开启外设时钟、GPIO 模式、复用功能、NVIC/中断源和标志位处理；寄存器字段以具体型号参考手册为准。

## 程序设计检查表

- 输入条件、变量范围、结果格式和存储空间是否已定义？
- 循环的初值、终止条件、计数范围和溢出行为是否清楚？
- 直接地址、立即数、位地址、内部/外部存储器访问是否正确？
- 子程序和中断是否保存会改动的寄存器，堆栈是否有足够空间？
- 定时、延迟或串口波特率的计算是否基于正确的时钟？
- 是否用一个最小例子手工跟踪关键寄存器与标志位？

## 典型综合题的组织方式

拿到“定时扫描、按键控制、串口收发、动态显示”等题目时，先把需求画成状态机或流程图，再拆分初始化、主循环、定时中断和数据处理。定时中断只负责节拍或采样，较重的计算放到主循环；按键消抖应使用明确的时间策略；显示扫描与按键读取要考虑共享端口和刷新周期。硬件接线、有效电平和晶振频率都属于题目条件，不能凭经验补设。

## 实验和考试的分配

实验调试从最小可观察信号开始：确认电源与时钟、单引脚输出、单个定时器/中断、串口回环，再组合模块。出现故障时记录预期与实测现象、寄存器值和最小代码片段。考试复习则把课件框架、近年卷和错题结合起来：先闭卷做，再对照答案定位知识边界，最后重新独立推导。
