# 微机原理与应用：专题笔记

## 专题一：8051 存储器与指令边界

8051 的程序存储器、片内 RAM、SFR 和片外数据 RAM 是不同地址空间。MOV 访问内部数据空间，MOVX 访问外部数据空间，MOVC 从程序存储器取常量表。指令题先写寻址方式、访问空间、操作数宽度，再跟踪 A、B、DPTR、SP 和标志位。

## 专题二：汇编程序设计

把算法分为初始化、主循环、子程序和异常/中断服务。多字节加减从低字节开始传递 CY；比较题要区分无符号比较和带符号比较；DJNZ、CJNE 的跳转条件和相对范围要逐条核对。查表程序常用 MOVC A,@A+DPTR，调用子程序前后要规划堆栈和现场保护。

## 专题三：中断、定时器与串口

每个外设按“时钟源—模式寄存器—标志位—初始化—服务流程”整理。经典 12T 内核中，机器周期与晶振相关，但具体芯片可能是 1T，计时初值不能脱离型号直接套用。中断服务程序要保存会修改的寄存器，尽量短，并清楚说明标志位由硬件还是软件清除。

串口题先确定波特率发生器和帧格式，再写发送/接收标志位的时序。轮询适合简单任务，中断适合并发处理，但必须处理溢出和共享缓冲区。

## 专题四：接口扩展

存储器扩展要画地址总线、数据总线、读写控制和片选译码。键盘扫描要考虑行列有效电平和按键消抖；动态显示要写扫描周期和刷新频率，避免肉眼闪烁。串行扩展则重点看时钟、数据方向和帧格式。

## 专题五：Cortex-M/STM32 迁移

Cortex-M 的中断向量、NVIC、GPIO 复用、外设时钟和 DMA 是 8051 体系之外的新重点。配置一个外设至少包含：开启总线时钟、设置 GPIO 模式、配置外设寄存器、使能中断/NVIC、清除状态标志、编写服务函数。具体寄存器字段必须以目标芯片参考手册为准。

## 专题六：综合实验与应试

“定时扫描 + 按键控制 + 串口收发 + 数据采样”题应先画状态机，再拆成初始化、定时中断、主循环和数据缓冲。实验调试从最小可观察信号开始：先确认时钟和单引脚，再加入定时器、串口、ADC 和显示。资料入口：[2026 复习](resources/microcomputer-review-2026.pdf)、[MOV 代码专项](resources/microcomputer-mov-practice.pdf)、[题库](resources/microcomputer-question-bank.pdf)。
