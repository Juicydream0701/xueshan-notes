# 汇编程序设计

汇编程序的重点是明确数据放在哪里、寄存器如何分工、分支条件如何形成。写程序前先确定输入、输出、工作区、边界条件和可被中断打断的共享数据。

## 汇编语句与伪指令

| 伪指令 | 用途 | 例子 |
| --- | --- | --- |
| `ORG` | 设置后续代码或数据的汇编地址 | `ORG 0000H` |
| `END` | 标记源程序结束 | `END` |
| `EQU` | 为常量或寄存器地址命名 | `COUNT EQU 30H` |
| `DB` / `DW` | 定义字节 / 字数据 | `TABLE: DB 01H,02H` |
| `DS` | 预留存储空间 | `BUFFER: DS 16` |
| `BIT` | 为位地址定义符号 | `READY BIT 20H` |

标签用于表示代码入口或数据位置；注释解释设计意图。`#20H` 是立即数，`20H` 通常是直接地址，两者不能混用。

## 从算法到程序

1. 写清输入和输出的格式、范围与存储地址。
2. 把问题拆成初始化、循环体、终止条件和异常/边界处理。
3. 分配寄存器和 RAM，避免一个寄存器承担互相冲突的角色。
4. 为每个循环写出循环不变量：指针当前指向什么、计数器还剩多少、结果累计到哪里。
5. 先用一组小数据手算，再逐条跟踪汇编程序。
6. 若使用子程序或中断，定义参数、返回值、会改动的寄存器和现场保护规则。

## 常见结构

### 顺序与分支

顺序结构按指令排列执行。单分支通常由 `JZ/JNZ`、`JC/JNC`、`JB/JNB` 或 `CJNE` 组成；多分支可用逐项比较或查表转移。写条件时要分清无符号大小比较与有符号数比较，8051 的 CY 规则不能直接代替有符号比较。

### 计数循环

`DJNZ Rn, LOOP` 先递减，再在结果非零时回到 LOOP。若初值为 0，递减会回绕到 `FFH`，所以“循环 0 次”必须单独处理。

```asm
        MOV  R7, #10
LOOP:   ; 循环体
        DJNZ R7, LOOP
```

### 查表

常量表放在程序空间时使用 `MOVC`。先把表首地址放入 DPTR，再把索引放入 A：

```asm
        MOV  DPTR, #TABLE
        MOV  A, INDEX
        MOVC A, @A+DPTR
```

要检查索引是否越界；表地址和偏移相加不能超出预留的代码空间。

### 多字节加减

从最低字节开始用 `ADD/ADDC` 累加。减法从低字节开始，首字节前清 CY，后续字节用 `SUBB` 传递借位。结果长度比操作数长时，要单独保存最终进位或溢出信息。

## 子程序与现场

子程序使用 `ACALL/LCALL` 进入、`RET` 返回。调用会把返回地址放入片内堆栈；若子程序会修改调用者仍需使用的寄存器，应在入口 `PUSH` 并在返回前按相反顺序 `POP`。堆栈空间要足以容纳嵌套调用及中断现场。

中断服务程序与普通子程序不同：入口是硬件向量，通常由硬件压入返回 PC，程序需要自行保护 A、PSW、DPTR 等会使用的现场，最后使用 `RETI`。

## 常见错误

- 把地址写成立即数，漏写 `#`，或把常数误当 RAM 地址。
- `SUBB` 前没有处理 CY，导致减法结果受上一条指令影响。
- 忘记 `MOVX`、`MOVC` 与 `MOV` 对应不同存储空间。
- 循环计数初值、循环次数和 `DJNZ` 的回绕行为不一致。
- 多字节运算没有从低字节向高字节传递 CY。
- 子程序或中断改写了主程序仍在使用的寄存器。
- 堆栈、变量区、缓冲区重叠，或堆栈增长越过 RAM 边界。
