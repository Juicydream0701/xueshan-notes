# 80C51 指令系统

## 先判断寻址方式

寻址方式说明操作数在哪里。读程序时先标出操作数来源，再计算执行结果。

| 寻址方式 | 例子 | 含义 |
| --- | --- | --- |
| 立即寻址 | `MOV A, #35H` | `35H` 是常数；`#` 表示立即数 |
| 寄存器寻址 | `MOV A, R3` | 操作数在当前寄存器组的 R3 |
| 直接寻址 | `MOV A, 30H` | `30H` 是内部 RAM 或可直接寻址 SFR 的地址 |
| 寄存器间接寻址 | `MOV A, @R0` | R0 中保存 RAM 地址，`@` 表示取该地址处的数据 |
| 位寻址 | `SETB P1.0` | 对位寻址 RAM 或支持位操作的 SFR 操作 |
| 变址寻址 | `MOVC A, @A+DPTR` | A 作为偏移量，DPTR 作为程序空间表基址 |
| 相对寻址 | `JNZ LOOP` | 指令编码保存有符号 8 位偏移，范围为下一条指令附近的 -128 到 +127 字节 |

`@R0`、`@R1` 主要用于内部 RAM 间接访问；外部数据空间需要 `MOVX`。8051 的直接寻址与寄存器间接寻址在 8052 高 RAM 区还承担区分 SFR/RAM 的作用。

## 数据传输指令

| 指令 | 空间 | 典型用途 |
| --- | --- | --- |
| `MOV` | 内部 RAM、寄存器、SFR | 通用数据移动；不支持任意两个 RAM 单元直接互传时，借助 A 或临时寄存器 |
| `MOVX` | 外部数据 RAM | `MOVX A,@DPTR` 读；`MOVX @DPTR,A` 写 |
| `MOVC` | 程序存储器 | `MOVC A,@A+DPTR` 或 `MOVC A,@A+PC` 查常量表 |
| `PUSH` / `POP` | 内部 RAM 堆栈 | 保存和恢复直接地址指定的字节；顺序相反才能恢复原值 |
| `XCH` / `XCHD` | 寄存器或内部 RAM | 交换整字节或低半字节 |

最重要的辨别口诀是：`MOV` 操作内部数据，`MOVX` 操作外部数据，`MOVC` 从代码空间查表。执行外部 RAM 访问时由硬件产生 `/RD` 或 `/WR`，不是 `/PSEN`。

## 算术与标志位

- `ADD A, src` 做 8 位加法；`ADDC` 还把 CY 加入结果，适用于多字节加法。
- `SUBB A, src` 计算 `A - src - CY`。普通减法前通常先 `CLR C`；CY 表示借位条件。
- `INC`、`DEC` 对指定操作数加一或减一；指令是否改变标志位要按该指令定义逐条确认，不能只凭结果猜测。
- `MUL AB` 得到 16 位无符号积，高字节放 B、低字节放 A；结果高字节非零时 OV 置位，CY 清零。
- `DIV AB` 以 B 为除数，商放 A、余数放 B；除数为零时 OV 置位。
- `DA A` 用于对前面的 BCD 加法结果作十进制调整，不是任意二进制运算后的通用转换指令。
- 有符号数溢出看 OV；无符号进位/借位看 CY。两个标志回答的问题不同。

多字节运算通常从最低字节开始，每字节完成后通过 CY 把进位或借位传给下一字节。

## 逻辑、移位与位操作

- `ANL`、`ORL`、`XRL` 分别实现按位与、或、异或，常用于屏蔽、置位、翻转位域。
- `RL/RR` 在 A 内循环；`RLC/RRC` 把 CY 纳入循环路径。
- `CLR`、`SETB`、`CPL` 可直接操作可寻址位；`JB`、`JNB`、`JBC` 按位状态跳转，`JBC` 跳转时还清除该位。
- 位操作适合实现开关量控制和布尔逻辑，避免不必要地改写同一端口上的其他位。

## 程序转移与调用

| 指令 | 范围 / 行为 | 常见用途 |
| --- | --- | --- |
| `SJMP rel` | 相对短跳转，偏移为有符号 8 位 | 局部循环和条件分支 |
| `AJMP addr11` | 同一 2 KB 页面内跳转 | 短地址转移 |
| `LJMP addr16` | 64 KB 代码空间内任意地址 | 长距离跳转 |
| `ACALL` / `LCALL` | 调用子程序并把返回地址压栈 | 分别用于短范围和全空间调用 |
| `RET` / `RETI` | 子程序返回 / 中断服务返回 | 中断服务程序必须用 `RETI` |
| `CJNE` | 不相等时跳转；比较时 CY 反映无符号大小关系 | 分支选择和范围检查 |
| `DJNZ` | 操作数减 1，非零时跳转 | 计数循环 |

计算相对偏移时，以当前指令之后的地址作为基准。指令长度、运行周期和跳转范围是三个不同概念，做题时分别计算。

## 做题检查顺序

1. 记录 A、B、DPTR、R0/R1、RAM、堆栈和相关位的初值。
2. 给每个操作数标出寻址方式及其所在空间。
3. 按指令顺序更新数据；涉及 CY 时单独记下它的旧值和新值。
4. 遇到跳转时先算条件，再按相对地址规则确定是否转移。
5. 最后核对机器码长度、堆栈变化以及题目要求的标志位。
