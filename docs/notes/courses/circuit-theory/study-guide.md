## 1. 开算前的草稿：把方程来源留下来

先圈出待求量和参考端口；标节点、极性和电流箭头；写清“直流稳态、正弦稳态、换路后暂态”中的哪一种。再比较节点电压数和独立网孔数，选择更少未知量的方法。最后把控制量定义、初始条件、负载限制写在方程旁边，之后再代数值。

只有参考方向固定，负数才有明确意义；只有题设的约束写全，矩阵解才有物理含义。看上去更短的算法，如果丢了受控量或改掉了待求端口，不能算巧解。

## 2. 基本模型与源处理

| 内容 | 关系或规则 | 使用条件 |
| --- | --- | --- |
| 关联参考方向功率 | $p=ui$ | 电流流入电压正端；否则吸收功率为 $-ui$ |
| 电阻 | $u=Ri$ | 常数线性电阻；非线性元件另写VCR |
| 电容 | $i=Cdu/dt$，$w=Cu^2/2$ | 线性恒定电容 |
| 电感 | $u=Ldi/dt$，$w=Li^2/2$ | 线性恒定电感，互感另计交叉项 |
| 独立电压源置零 | 短路 | 保留原串联内阻和其余连接 |
| 独立电流源置零 | 开路 | 保留原并联内阻和其余连接 |
| 受控源 | 保留控制关系 | 叠加、等效电阻、小信号分析均不能任意删除 |

直流稳态的电容开路、电感短路不适用于换路瞬间。求输入/等效电阻时，只把内部独立源置零，外加测试源保持工作。

## 3. 方程法：特殊源放在哪里

- **未知节点之间的电压源**：用超节点KCL加电压约束，或增加源电流未知量。
- **两个网孔之间的电流源**：用超网孔KVL加电流约束。
- **接地电压源**：对应节点电压直接已知，注意源极性。
- **只属于一个网孔的电流源**：对应网孔电流直接已知，注意箭头。

普通电阻节点导纳矩阵中，对角线是相连导纳和，非对角线是共享导纳负值；含受控源时不一定对称。网孔法要求平面图，任意网络可改用独立回路法。共享电阻电流是相邻网孔电流的代数差，不能把两个网孔电流直接相加。

## 4. 定理：公式旁必须留住前提

$$V_{th}=V_{oc},\qquad I_N=I_{sc},\qquad V_{th}=I_NR_{th}.$$

对于端口关系良好的线性网络，$R_{th}=V_{oc}/I_{sc}$ 在比值存在时可用，含受控源也不自动失效；无独立源导致两者同为零、或理想源退化时，就必须回到测试源和端口关系。测试电流方向取流入网络，$R_{th}=V_t/I_t$。

| 问题 | 条件与结果 |
| --- | --- |
| 直流正电阻源最大负载功率 | $R_L=R_{th}>0$，$P_{\max}=V_{th}^2/(4R_{th})$ |
| 交流可调复阻抗 | $Z_L=Z_{th}^*$，有效值下 $P_{\max}=|V_{th}|^2/(4\operatorname{Re}Z_{th})$，要求正实部 |
| 交流只允许纯电阻负载 | $R_L=|Z_{th}|$，不能默认等于 $\operatorname{Re}Z_{th}$ |
| 叠加 | 适用线性电压/电流；不直接叠加功率，受控源保留 |
| 互易 | 先确认网络互易及端口/激励约定；线性不自动推出互易 |

最大功率时戴维南等效模型的内阻与负载各耗一半功率，不代表原网络从真实电源到负载的效率必为50%；内部其他支路仍可能耗能。

## 5. 交流：统一有效值余弦基准

若 $u(t)=\sqrt2U\cos(\omega t+\theta)$，相量为 $\underline U=U\angle\theta$。同一频率下

$$Z_R=R,\quad Z_L=j\omega L,\quad Z_C=\frac1{j\omega C},\quad
\mathcal S=\underline U\underline I^*=P+jQ.$$

不同频率不能合并成一个相量。功率中必须共轭电流；时域正弦系数是峰值，要先换有效值。串联RLC谐振 $\omega_0=1/\sqrt{LC}$，$Q=\omega_0L/R$，带宽 $\Delta\omega=R/L$；这些带宽公式不能未经说明照搬到含线圈损耗的任意并联网络。

非正弦周期信号先合并同频项，再按正交性计算总有效值：

$$X_{\mathrm{rms}}^2=X_0^2+\sum_{n\ge1}X_{n,\mathrm{rms}}^2.$$

若电压电流都非正弦，平均功率是各同频分量功率之和；总功率因数仍为 $P/(U_{\mathrm{rms}}I_{\mathrm{rms}})$，一般不存在一个统一的总相角。

## 6. 暂态：把正确的三要素写成三行

无冲激时，连续条件只对状态量适用：

$$u_C(0^+)=u_C(0^-),\qquad i_L(0^+)=i_L(0^-).$$

稳定一阶网络、换路后恒定激励：

$$x(t)=x(\infty)+[x(0^+)-x(\infty)]e^{-t/\tau}.$$

$$\boxed{\tau_{RC}=R_{eq}C,\qquad \tau_{RL}=\frac L{R_{eq}}.}$$

$R_{eq}$ 从**换路后**的储能端口看进去，独立源置零，受控源保留。其他支路电压电流的 $0^+$ 值用瞬时电路求，不能一律继承 $0^-$。正弦激励改用随时间变化的特解加自然项，不能套一个常数终值。

串联RLC：$\alpha=R/(2L)$，$\omega_0=1/\sqrt{LC}$；欠阻尼时 $\omega_d=\sqrt{\omega_0^2-\alpha^2}$。二阶需要两个独立初值。并联RLC的阻尼系数应重新从方程得到，不能直接复制串联式。

## 7. 三相：幅值公式和相量公式分开记

正序对称电源 $\underline U_{AB}=\sqrt3\underline U_{AN}e^{j30^\circ}$。对称星接 $I_L=I_p,U_L=\sqrt3U_p$；对称角接 $U_L=U_p,I_L=\sqrt3I_p$，同时注意30°偏移。

通用总复功率逐相求和。对称时可用幅值式：

$$P=\sqrt3U_LI_L\cos\varphi,\qquad Q=\sqrt3U_LI_L\sin\varphi.$$

不要直接把实际带角度的 $\underline U_{AB}$ 和 $\underline I_A^*$ 相乘再乘 $\sqrt3$，那样会引入30°误差。负载不平衡、无理想中性线时，先列星点KCL；两瓦特表的和测三线制总有功，用差求无功则另需对称正弦前提。

## 8. 复习怎么安排才不空转

**第一轮理解**：读讲义，盖住例题结果，自己完成关键方程；讲不清公式条件就回到定义。**第二轮练习**：每章完成两道不同结构的题，最后才展开答案，按“模型、方向、方程、计算、单位”标记错误。**第三轮综合**：完成[九道综合题](topics/07-problems.md)，记录每题第一次卡住的位置，回到相应章而不是重新从第一页浏览所有资料。

原资料中的同类题建议分两次用：第一次正常求解；隔几天换一种方法复做，例如节点法结果用戴维南复核，暂态用初始KCL和终值复核。重复抄已经会的推导，不如追问“如果电流源换方向、负载限为纯电阻、初始值不为零，哪里要重算”。

## 9. 与模拟电子怎样衔接

电路原理的线性求解方法用于模电，但模电先要判断器件工作区和静态点。在直流分析中按器件模型确定偏置；小信号分析时，把直流独立源置为交流零，保留输入信号，并替换为围绕静态点的增量模型。不能把所有交流源一律置零，否则连待放大的输入也会消失。进入[模拟电子](../analog-electronics/index.md)后，还要检查幅度是否足够小、输出是否饱和，以及工作区假设能否成立。
