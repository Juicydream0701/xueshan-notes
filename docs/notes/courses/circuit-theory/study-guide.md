# 电路与电子技术Ⅰ：电路部分应试路线

这页按考试答题顺序组织。每道题都先写“状态—模型—未知量—约束”，再开始计算，能显著减少符号和模型切换造成的失分。

## 计算题的通用草稿模板

1. **状态**：写明“直流稳态 / 正弦稳态 / $t>0$ 暂态”。
2. **参考**：标节点、支路方向、极性和相量约定。
3. **模型**：说明电容、电感、受控源、耦合元件如何处理。
4. **路线**：一句话写“节点法 / 网孔法 / 戴维南 / 相量法 / 一阶响应”。
5. **方程**：先列通式，再代数值，保留关键中间量。
6. **复核**：单位、极限、功率、初值和终值至少检查两项。

## 题型选择表

| 题目特征 | 优先方法 | 必查点 |
| --- | --- | --- |
| 支路多、公共参考点清楚 | 节点电压法 | 超节点的电压约束是否补上 |
| 平面电路、网孔少 | 网孔电流法 | 共享支路电流的正负号 |
| 只关心一个负载端口 | 戴维南/诺顿 | 求 $R_{th}$ 时受控源是否保留 |
| 多个独立源、线性响应 | 叠加 | 源置零规则；功率不能叠加 |
| 正弦源或频率响应 | 相量法 | 峰值/有效值、共轭和相位 |
| 开关、电容、电感 | 一阶暂态 | 初值连续、终值、$R_{eq}$ |
| 对称三相 | 相电路 | 线量与相量换算、功率公式 |

## 暂态题的阅卷友好写法

不要直接写指数结果。先把下面三行写出来：

$$x(0^+)=x(0^-),\qquad x(\infty)=\text{切换后直流终值},\qquad \tau=\frac{\text{储能参数}}{\text{从端口看到的等效电阻}}.$$

然后写

$$x(t)=x(\infty)+[x(0^+)-x(\infty)]e^{-t/\tau}.$$

如果开关改变了电路拓扑，$R_{eq}$ 必须重新求；不能把开关前的电阻直接沿用到开关后。

## 电路部分与模拟部分怎样衔接

电路题练的是“建立线性模型并检查结果”，模拟题则在此基础上增加“先判断器件工作区，再选择小信号模型”。因此复习顺序建议是：

1. 用节点法、戴维南等效和一阶暂态把电路计算基本功练稳；
2. 进入[模拟电子部分](../analog-electronics/index.md)，先做二极管和 BJT/MOS 的直流状态判断；
3. 再把交流电源置零、画小信号等效电路，计算增益和输入/输出电阻；
4. 最后用反馈、运放、稳压和振荡综合题检验模型切换能力。

## 考前三轮

- **第一轮**：只整理模型和公式前提，给每个公式写“何时可用”。
- **第二轮**：按题型限时完整作答，答案只在最后用于定位具体卡点。
- **第三轮**：重做错题，按“方向/方程/模型/代数/单位”归类；考前再做一套综合题并预留检查时间。
