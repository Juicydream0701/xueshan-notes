# 01 电路原理

[打开分析流程与复习路线 →](study-guide.md)

电路分析的核心，是用元件模型和基尔霍夫定律把物理网络变成可解方程。复习按“建模—求解—校验”组织。

## 元件模型与基本定律

电阻满足 $u=Ri$；电容满足 $i_C=C\,du_C/dt$，电感满足 $u_L=L\,di_L/dt$。电容电压、电感电流连续：$u_C(0^+)=u_C(0^-)$、$i_L(0^+)=i_L(0^-)$（存在冲激时例外）。KCL 是节点电流代数和为零，KVL 是回路电压代数和为零。先统一参考方向，负结果表示实际方向相反；受控源始终保留。

## 等效变换与电路方程

电压源 $V_s$ 串联 $R$ 等效为电流源 $I_s=V_s/R$ 并联同一电阻。节点法对未知节点电压列 KCL；含跨节点电压源时设超节点。网孔法对平面电路列 KVL；电流源位于相邻网孔时设超网孔。含受控源求 $R_{th}$ 时，独立源置零后加测试源。

## 线性电路定理

- **叠加**：各独立源单独作用的线性响应相加。电压源置零为短路、电流源置零为开路；受控源保留。功率不直接叠加。
- **戴维南/诺顿**：端口等效为 $V_{th}$ 串联 $R_{th}$ 或 $I_N$ 并联 $R_{th}$，且 $V_{th}=I_NR_{th}$。
- **最大功率传输**：直流电阻网络 $R_L=R_{th}$；交流网络 $Z_L=Z_{th}^*$。
- **特勒根与互易**：特勒根适用于同拓扑满足 KCL/KVL 的网络；互易定理需满足线性、双向等条件。

## 正弦与非正弦稳态

相量阻抗为 $Z_R=R$、$Z_L=j\omega L$、$Z_C=1/(j\omega C)$。不同频率分量不可直接合成一个相量。有效值相量下 $S=\underline U\underline I^*=P+jQ$。非正弦周期量按直流和各次谐波分别求稳态响应后叠加；平均功率按正交谐波计算，勿混淆峰值与有效值。

## 一阶暂态与三相电路

一阶响应 $x(t)=x(\infty)+[x(0^+)-x(\infty)]e^{-t/\tau}$。RC 有 $\tau=R_{eq}C$，RL 有 $\tau=L/R_{eq}$；先求切换前储能初值，再用连续性求 $0^+$，求切换后终值与等效电阻。拓扑变化后必须重算 $R_{eq}$。

对称三相星形 $U_L=\sqrt3U_{ph}, I_L=I_{ph}$；三角形 $U_L=U_{ph}, I_L=\sqrt3I_{ph}$。总有功功率 $P=\sqrt3U_LI_L\cos\varphi$。不平衡负载需逐相分析。

## 解题检查清单

1. 标清参考方向与被动符号约定；2. 暂态先处理初值连续性；3. 求等效电阻时区分独立源与受控源；4. 用单位、极限状态、功率守恒或回代检查。
