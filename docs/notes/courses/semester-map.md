# 四个学期的课程地图

这里按课程文件夹中的四个学期，整理一条“基础数学与编程 → 物理与 AI → 电路与数学工具 → 专业综合”的回看路线。它不是成绩单，也不追求把每门课都搬上网站；只有已经形成复习页或精选资料的课程才放入主站入口。

## 2024 秋冬：从数学和编程开始

这一阶段最值得留下的是微积分、线性代数和 C 程序设计。微积分负责变化率与积分，线性代数负责矩阵和空间，C 语言则把抽象逻辑变成可运行的程序。

- [线性代数（甲）](foundations/linear-algebra/index.md)：先掌握矩阵运算、线性方程组、特征值，再回看二次型。
- [C 程序设计基础及实验](foundations/c-programming/index.md)：以数组、指针、结构体和文件操作为主线，配合调试训练。

## 2025 春夏：把数学和物理接到工程问题上

大学物理和常微分方程是工程课程的重要前置；人工智能基础则提供了数据、模型和实验的另一条工具链。

- [大学物理（甲）Ⅰ](foundations/college-physics/index.md)：力学、振动与波、热学、静电场按物理过程串联。
- [常微分方程](foundations/ordinary-differential-equations/index.md)：把一阶、二阶和线性方程组整理成方法选择表。
- [人工智能基础（A）](foundations/ai-foundations/index.md)：从问题建模和数据处理进入机器学习、深度网络与大模型。

## 2025 秋冬：概率、复变与电路基础

概率统计与复变函数都在为后续信号分析、控制和电力电子打底。电路与电子技术Ⅰ则把数学工具落到真实的电压、电流和器件模型上。

- [概率论与数理统计](foundations/probability-statistics/index.md)：重点看随机变量、数字特征、估计和检验。
- [电路原理](circuit-theory/index.md)：从这一页进入专业主线，练习“建模—列式—求解—检查”。

## 2026 春夏：离散结构与专业课汇合

离散数学、微机原理、信号分析、电网络和工程电磁场构成当前专业学习的骨架。离散数学负责逻辑与图结构，其余课程逐步进入系统、硬件和场的层面。

- [离散数学](foundations/discrete-mathematics/index.md)：集合、关系、函数、图、树和逻辑是后续数字系统与算法的共同语言。
- [专业课程总览](index.md)：从电路、模拟、数字，到信号、微机、电网络和电磁场逐层推进。

## 推荐回看顺序

1. 先用线性代数、C 语言和大学物理恢复基础概念。
2. 再看常微分方程、概率统计和离散数学，补齐工具。
3. 最后按电路 → 模拟/数字 → 信号/微机 → 电网络/电磁场的顺序复习专业课。
4. 每学完一门课，留下“一个核心模型、一个典型例题、一个仍未解决的问题”，比保存大量重复课件更有价值。
