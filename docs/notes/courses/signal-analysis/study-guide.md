# 信号分析与处理：分析方法的选择

这门课难点往往不在某个变换公式，而在于识别题目属于连续/离散、周期/非周期、时域/频域还是系统响应问题。先分类，再选工具，最后核对定义和收敛条件。

## 系统性质先行

检查线性、时不变、因果和稳定性。对 LTI 系统，冲激响应决定系统；连续时间卷积为 $y(t)=x(t)*h(t)$，离散时间卷积为 $y[n]=x[n]*h[n]$。BIBO 稳定要求连续时间 $h(t)$ 绝对可积或离散时间 $h[n]$ 绝对可和。因果性对应冲激响应在负时间/负序号处为零。

## 变换工具如何选

| 问题特点 | 常用表示 | 检查点 |
| --- | --- | --- |
| 连续周期信号 | 傅里叶级数 | 基频、系数约定、直流分量 |
| 连续非周期信号 | 傅里叶变换 | 收敛性、频率单位、幅相谱 |
| 离散无限长序列 | DTFT | $2\pi$ 周期性与频率归一化 |
| 有限长数据的数值频谱 | DFT/FFT | 采样长度、频率栅格、窗函数和泄漏 |
| 差分方程与离散系统 | Z 变换 | 单边/双边定义、初值、ROC |
| 微分方程与连续系统 | 拉普拉斯变换 | 初始条件、极点、收敛域 |

傅里叶变换的时移会引入线性相位因子；频移会平移频谱。实信号频谱有共轭对称性。计算 DFT 前明确是否采用 $1/N$ 归一化、指数正负号和采样间隔，避免幅度与频率轴错误。

## 采样和混叠

采样频率应满足题目所需的带限假设和奈奎斯特条件，实际采集还要预留抗混叠滤波器过渡带。若采样率不足，频谱副本重叠，事后数字滤波无法还原已经折叠的频率成分。频率分辨率由观测时长决定，增加采样点但不增加观测时长并不会自动改善真实频率分辨能力。

## 滤波器与实现

先明确通带、阻带、截止频率、纹波、相位或群时延要求，再选择低通、高通、带通或带阻类型。FIR 可通过有限冲激响应实现，常具有稳定性和线性相位设计优势；IIR 用反馈结构实现，阶数可能较低，但需检查稳定性和相位特性。滤波器的理论指标、系数量化和实际计算精度也要分别看待。

## 频谱题的作答模板

1. 写信号定义、周期/频率和变换约定。
2. 选直接积分/求和，或使用线性、时移、调制、卷积等性质。
3. 分别给出幅度和相位，标出单位与频率轴。
4. 检查共轭对称、周期性、能量/功率和极限情况。
5. 若转到数值实现，再说明采样率、窗长、频率分辨率和 FFT 归一化。

## 学期学习建议

课程经验提醒这门课概念跨度大，平时理解比考前只记公式更重要。建议每学完一种变换就做“定义—性质—典型信号—系统应用”四格总结；之后对照三套自测或历年题做完整推导，再专门练容易混淆的连续与离散、周期与非周期概念。资料见[课程目录](../index.md)，个人课程经验见[课程与实验地图](../../campus/experiences.md)。
