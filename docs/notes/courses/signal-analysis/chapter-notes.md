# 信号分析与处理：专题笔记

## 专题一：连续与离散信号

先区分连续时间 x(t) 与离散序列 x[n]，再判断周期、能量/功率和奇偶性。连续周期信号满足存在最小 T0 使 x(t+T0)=x(t)；离散正弦只有在频率与 2π 的比值为有理数时才严格周期。单位冲激的抽样性质是卷积和变换推导的基础。

## 专题二：LTI 系统与卷积

线性、时不变系统由冲激响应完全描述。连续系统输出为
$$y(t)=x(t)*h(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)d\tau,$$
离散系统则为 y[n]=Σx[k]h[n-k]。做题可利用交换、结合和分配律改变卷积顺序；因果 LTI 系统要求 h(t) 在负时间为零，BIBO 稳定要求绝对可积/可和。

## 专题三：傅里叶级数与傅里叶变换

周期信号先求基频，再按题目采用的三角形式或复指数形式计算系数。偶信号只保留余弦项，奇信号只保留正弦项；非对称波形的直流分量不能漏掉。傅里叶变换中的时移对应线性相位，调制对应频谱搬移，卷积对应频域相乘。

频谱图要标明横轴单位、双边/单边约定和幅值归一化。实信号的频谱具有共轭对称性，利用这一性质可检查手算结果。

## 专题四：采样、DTFT、DFT 与 FFT

采样把连续频谱按 fs 周期复制。带限信号要避免混叠，采样率需高于两倍最高频率并为抗混叠滤波器留出过渡带。DTFT 对离散序列给出连续且 2π 周期的频率表示；DFT 是有限点采样，频率间隔为 fs/N。

DFT 默认带来循环卷积，线性卷积要补零到至少 Nx+Nh-1 点。FFT 只是计算 DFT 的快速算法，蝶形运算的旋转因子、正负号和归一化约定必须与软件一致。有限观测会产生谱泄漏，窗函数能改变旁瓣和主瓣宽度，不能消除信息不足。

## 专题五：Z 变换与系统响应

Z 变换把差分方程变成代数式。系统函数 H(z)=Y(z)/X(z) 的极点、零点和收敛域共同决定因果性与稳定性。相同代数表达式在不同 ROC 下可能对应不同序列，因此不能只写有理式而不写 ROC。

系统响应通常拆成零输入、零状态和全响应。单位阶跃、单位冲激和指数序列是高频测试输入；求出结果后要检查初值、终值和因果性。

## 专题六：滤波器与实验实现

先写通带、阻带、截止频率、纹波和阶数指标，再决定低通、高通、带通或带阻。FIR 适合线性相位，IIR 阶数较低但要检查极点稳定性。实际实现还会受到系数量化、有限字长、采样抖动和 ADC 噪声影响。
