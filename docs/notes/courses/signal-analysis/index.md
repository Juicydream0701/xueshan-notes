# 05 信号分析与处理

[打开系统分析、变换选型与采样学习路线](study-guide.md)

信号题的主线是“表示信号 → 分析系统 → 频域变换 → 采样与滤波”。连续时间和离散时间符号不能混用。

## 信号与系统

判断线性、时不变、因果和稳定性。LTI 系统满足卷积：连续时间 $y(t)=x(t)*h(t)$，离散时间 $y[n]=x[n]*h[n]$。单位冲激响应完全刻画 LTI 系统；BIBO 稳定要求 $h(t)$ 绝对可积或 $h[n]$ 绝对可和。

## 傅里叶与谱分析

周期信号用傅里叶级数，非周期信号用傅里叶变换。时移对应频域线性相位，卷积对应频域相乘。幅度谱和相位谱要标清频率轴、单位及单双边定义；实信号频谱具有共轭对称性。

## DTFT、DFT 与 FFT

DTFT 是离散时间信号的连续频率表示；DFT 对有限长度序列频率采样。DFT 的循环卷积与线性卷积不同，线性卷积需补零。FFT 以分治降低复杂度，蝶形运算中注意旋转因子指数和归一化约定。

## Z 变换与采样

Z 变换的收敛域决定序列性质和系统因果性；差分方程在零初始条件下用 $H(z)=Y(z)/X(z)$ 求系统函数；非零初始条件要另外保留零输入响应。采样频率需满足 $f_s>2f_{max}$ 才能避免带限信号混叠；实际系统用抗混叠低通滤波器。重建滤波器需保留目标基带并抑制频谱复制。

## 滤波器与失真

低通、高通、带通和带阻按通带/阻带定义。幅频失真来自通带增益不平坦，相频失真来自群时延变化；通信系统还需区分线性失真和非线性失真。设计滤波器时同时检查截止频率、过渡带、纹波和阶数。

## 解题流程

先写清信号定义和采样率，再选择变换；变换后标出收敛域/频率范围；最后用极限、单位和时域样点检查结果。

## 六、代表题：采样、频谱和重建

若连续信号最高频率为 (f_m)，采样频率 (f_s) 必须满足 (f_s>2f_m) 才能在理想带限条件下避免混叠。实际设计先放置抗混叠低通滤波器，再根据过渡带选择 (f_s)，而不是只把采样率设为两倍最高频率。

对长度为 (N)、采样率为 (f_s) 的记录，DFT 频率间隔为

$$
\Delta f=\frac{f_s}{N}.
$$

若信号频率不落在频率栅格上，会发生谱泄漏；加窗可以降低旁瓣但会扩大主瓣。分析题应同时写“采样率、记录长度、窗函数、单/双边谱”，否则频谱图无法复核。

## 七、变换选型与易错点

| 题目关键词 | 首选工具 | 需要写清的条件 |
| --- | --- | --- |
| 周期信号谐波 | 傅里叶级数 | 基频、系数约定、奇偶性 |
| 非周期连续信号 | 傅里叶变换 | 频率单位与收敛条件 |
| 有限离散记录 | DFT/FFT | 补零、窗函数、归一化 |
| 差分方程系统 | Z 变换 | 初始条件、ROC、因果性 |
| 采样与重建 | 频谱复制图 | 抗混叠滤波、重建带宽 |

常见逻辑错误是把 DFT 当成 DTFT 的连续曲线、把循环卷积当成线性卷积，或在未确认收敛域时由极点直接判断因果性。做卷积题时先画有限序列的支撑区间，再决定是否需要补零。
