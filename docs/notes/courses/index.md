# 课程笔记

按课程找内容，先看下面的分类；按学习经历回看，使用[学期地图](semester-map.md)。课程首页、详细讲解、复习提纲和原始PDF各有用途，具体见[阅读说明](../tools/reading-guide.md)。

[电路原理](circuit-theory/index.md)与[半导体物理](semiconductor-physics/index.md)提供分章讲义、推导和练习。各课程的总览、专题与速查提纲分别用于定位章节、学习知识和考前查阅；考试范围与符号约定以授课材料为准。

| 编号 | 课程 | 内容 |
| --- | --- | --- |
| 01 | [电路与电子技术Ⅰ：电路部分](circuit-theory/index.md) | 秋学期电路模型、网络定理、稳态、暂态、三相 |
| 02 | [电路与电子技术Ⅰ：模拟部分](analog-electronics/index.md) | 冬学期器件、放大、差分、反馈、振荡与电源 |
| 03 | [半导体物理](semiconductor-physics/index.md) | 能带、统计、输运、非平衡载流子、pn 结与接触 |
| 04 | [数字电子技术](digital-electronics/index.md) | 逻辑化简、组合逻辑、时序、计数与转换 |
| 05 | [电网络](electrical-networks/index.md) | 拉普拉斯、网络函数、矩阵、双口与传输线 |
| 06 | [信号分析与处理](signal-analysis/index.md) | 系统、频谱、DFT/FFT、Z 变换、采样与滤波 |
| 07 | [微机原理与应用](microcomputer/index.md) | 8051、汇编、中断、定时、接口与 Cortex-M |
| 08 | [工程电磁场与波](electromagnetics/index.md) | 静电、恒定场、时变场、平面波与传输 |
| 09 | [电力电子技术Ⅰ](power-electronics/index.md) | 器件、整流、斩波、逆变与交流变换 |
| 10 | [控制理论（乙）](control-theory/index.md) | 建模、时域、根轨迹、频域与校正 |
| 11 | [计算机网络与通信](computer-networks/index.md) | 分层、交换、IP、TCP/UDP 与应用协议 |
| 12 | [电子测量与智能仪器](measurement-instruments/index.md) | 误差、传感、采样、仪器与校准 |
| 13 | [宽带无线通信技术设计与实践](wireless-communications/index.md) | 链路预算、调制、同步、均衡与测试 |

## 实验与工程实践

工程图学与工程训练涉及工程表达、加工工艺和测量验证。

| 课程 | 适合什么时候看 | 核心价值 |
| --- | --- | --- |
| [工程图学](engineering-graphics/index.md) | 读图、作图或准备机械基础训练前 | 建立投影、剖视、尺寸链和工艺检查的统一流程 |
| [工程训练](engineering-training/index.md) | 进入实训、3D 打印、焊接或车削项目时 | 把材料、工序、设备、安全与测量组织成可复盘的工艺卡 |
| [电路与电子技术实验 II](circuit-electronics-experiments/index.md) | 进行 PSpice、运放、比较器和功放实验时 | 完成理论计算、仿真、实测与误差分析 |

## 基础课与数学工具

这组页面来自 2024 秋冬至 2026 秋冬五个学期的课程整理。资料只保留适合长期复习的文件，避免把教材、历年卷和重复课件全部搬到公开站点。

| 课程 | 适合什么时候看 | 核心价值 |
| --- | --- | --- |
| [C 程序设计基础及实验](foundations/c-programming/index.md) | 开始写程序、准备机考 | 把语法、指针、数组和调试连成完整流程 |
| [线性代数（甲）](foundations/linear-algebra/index.md) | 学习电网络、信号和控制前 | 建立矩阵、特征值和二次型的计算框架 |
| [大学物理（甲）Ⅰ](foundations/college-physics/index.md) | 进入电磁学和工程课前 | 用力学、振动、热学和静电场建立物理直觉 |
| [常微分方程](foundations/ordinary-differential-equations/index.md) | 学习动态系统、控制和电路暂态前 | 形成“识别方程—选方法—验结果”的解题习惯 |
| [人工智能基础（A）](foundations/ai-foundations/index.md) | 做数据分析、AI 实验或数模项目时 | 连接机器学习、神经网络和生成式 AI 的基本概念 |
| [概率论与数理统计](foundations/probability-statistics/index.md) | 读实验数据、做建模和信号分析时 | 从随机变量走到估计、检验和不确定性表达 |
| [离散数学](foundations/discrete-mathematics/index.md) | 学算法、数字系统和逻辑设计时 | 训练集合、关系、图、树和逻辑推理能力 |
| [微积分（甲）I–II](foundations/calculus/index.md) | 所有工程数学和专业课的前置 | 从极限、导数、积分走到多元、级数与变换 |
| [复变函数与积分变换](foundations/complex-analysis/index.md) | 学信号、控制和电磁场前 | 用解析函数、留数和变换处理复频域问题 |
| [大学物理（甲）Ⅱ](foundations/college-physics-2/index.md) | 学电磁场、波和半导体前 | 把电磁、波动光学和量子现象连成主线 |
