## 如何编译

1. 解压 ZIP，保持 `resource/` 文件夹与 `main.tex` 在同一个目录中。
2. 选择 **XeLaTeX**，在工程目录执行两次：

```sh
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

需要常见的 TeX Live/MiKTeX 宏包，例如 `ctex`、`exam`、`graphicx`、`titlesec`、`needspace`、`zhnumber` 等。请勿使用 pdfLaTeX。课程名中的「Ⅰ」使用模板已有的 XeLaTeX 中文字体设置，不依赖 `FandolSong-Bold.otf` 的硬编码字体文件名。
