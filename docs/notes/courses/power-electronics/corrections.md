## 1. 全课统一的符号

| 符号 | 本站约定 | 容易混淆的情况 |
| --- | --- | --- |
| $U_s$ | 单相交流有效值 | 正弦峰值为 $\sqrt2U_s$ |
| $U_{LL}$ | 三相线电压有效值 | 对称正弦相电压有效值为 $U_{LL}/\sqrt3$ |
| $U_d,V_d,V_{in}$ | 各章所定义的直流母线或输入电压 | 半桥的总母线不能与单个分压电容电压混用 |
| $\Delta i_{pp}$ | 电流纹波峰峰值 | 峰值偏差为其一半 |
| $\alpha$ | 相控触发延迟角 | 三相从自然换相点量，不一定从相电压零点量 |
| $\beta=\pi-\alpha$ | 有源逆变的触发引前角 | 与负载电流熄灭角不可跨题混用 |
| $\gamma=\beta-\mu$ | 简化换相模型的关断裕角 | $\mu$ 为重叠角，须确保 $\gamma/\omega$ 足够大 |
| $m_a,m_f$ | 幅值调制比、载波频率/基波频率 | 输出基波有效值仍取决于半桥/全桥/三相拓扑 |

## 3. 不能脱离条件使用的结论

**“功率因数等于 $\cos\alpha$”**：相控整流输入电流非正弦，总 PF 还含畸变因数。单相恒定直流电流理想桥为 $(2\sqrt2/\pi)\cos\alpha$，三相桥为 $(3/\pi)\cos\alpha$，具体定义见第三章。

**“Buck/Boost 的变比只由占空比决定”**：理想 CCM 才能直接采用常见三式；DCM 同时依赖负载、$L$ 与 $f_s$。同步整流允许负电流时，又与二极管 DCM 不同。

**“单极性纹波电感只有一个固定系数”**：半周钳位和双参考倍频实现不同；题目若未说明纹波为峰峰值还是幅值，还会多一个因子 2。本站数值题明确所用实现和定义。

**“ZVS/ZCS 没有开关损耗”**：它们只在满足状态与时序条件时减小特定过程损耗；循环电流、寄生电容、二极管、磁性元件和驱动仍有损耗。

**“某年份未考，所以无需复习”**：有限回忆卷反映当时题型，不足以决定今后的考试范围。复习先覆盖八章基础，再按本学期通知确定拓展深度。
