# 电力电子技术：变换器与波形分析

电力电子题通常围绕器件开关状态、输入输出波形、平均值/有效值和控制策略展开。先画开关状态，再写每个区间的电路方程。

## 1. 器件与开关模型

理想二极管只允许单向导通；晶闸管需满足触发和维持条件；MOSFET/IGBT 常按受控开关处理。实际分析要区分导通压降、反向恢复和开关损耗的影响，题目未说明时才使用理想模型。

## 2. 整流电路

单相半波、全控桥和半控桥的平均输出电压由导通区间决定。纯电阻负载时电流跟随电压，电感负载会延续电流并改变换相条件。三相桥式整流要画六个换相区间，平均值与相电压/线电压定义保持一致。

## 3. 直流斩波

Buck、Boost、Buck-Boost 的理想连续电流模式关系分别为

$$
V_o=DV_s,\qquad V_o=\frac{V_s}{1-D},\qquad V_o=-\frac{D}{1-D}V_s.
$$

写公式前确认电感电流是否连续。电感伏秒平衡和电容电荷平衡是推导稳态关系的通用工具；纹波计算要明确开关周期和占空比。

## 4. 逆变器与 PWM

单相桥逆变器通过改变开关组合产生交流输出。正弦 PWM 用调制波和载波比较，调制度决定基波幅值，载波比决定谐波分布。分析输出频谱时区分基波、载波侧带和死区引入的低次谐波。

## 5. 交流调压与变频

交流调压器通过改变晶闸管触发角改变有效值，负载为电感时要考虑电流延续角。矩阵变换器和交交变频器直接改变频率，题目常要求判断输出频率范围和波形。

## 6. 损耗、热设计与保护

导通损耗约为 (P_{on}=V_{on}I\) 或 (I^2R_{on})，开关损耗与电压、电流、开关时间和频率相关。热设计要从结温、热阻和环境温度反推散热要求。实际系统还要考虑过流、过压、dv/dt、di/dt 和栅极驱动隔离。

## 7. 解题流程

1. 列出开关周期和导通区间；
2. 对每个区间画等效电路；
3. 使用电感伏秒平衡/电容电荷平衡；
4. 求平均值、纹波和器件应力；
5. 用极限占空比、功率守恒和波形连续性检查。
