# 电力电子技术Ⅰ：专题笔记

本页保留五个专题的概要。需要完整推导、波形、数值题与原资料页码，请进入[八章详细讲义](index.md#chapters)；[历年题解答](exam-solutions.md)按可确认的回忆条件分步计算。

## 专题一：器件、开关与波形建模

理想电力开关只有导通和关断两种状态，导通时压降为零、关断时电流为零。真实器件还要考虑反向恢复、寄生电感、开关损耗和安全工作区。二极管的单向导电决定续流路径；晶闸管需要门极触发并在电流过零或强制换流后关断；MOSFET 适合高频，IGBT 适合中高压中频场景。

做拓扑题先不要急着写公式。第一步是给电感、电容和负载标参考方向；第二步列开关组合；第三步判断每个组合的实际可行性。若电感电流不能突变，开关切换瞬间一定存在续流通道；若电容电压不能突变，切换前后的电容电压应连续。这个“状态连续性”检查常常能发现错误的二极管方向。

开关损耗可粗略写为 $P_{sw}\approx\frac12VI(t_r+t_f)f_s$，导通损耗则与器件压降或 $R_{on}i^2$ 有关。提高频率能减小滤波器，却会增加开关损耗和 EMI，因此设计题通常需要在纹波、效率和体积间折中。

## 专题二：整流与功率因数

单相不可控桥的平均输出电压随输入正弦波的绝对值变化；全控桥通过触发角 $\alpha$ 调节平均值，连续电流时常见关系为 $U_d=U_{d0}\cos\alpha$。三相桥在每个时刻由最高相和最低相对应的器件导通，理想平均值与线电压有效值成正比。

整流分析应先确定相电压、器件导通区间和负载电压的对应关系，再求平均值。若有电感，电流会延续，换相期间可能出现重叠角 $\mu$，输出平均值下降并引入无功。若题目问功率因数，要区分位移因数与畸变因数：触发角导致基波相位滞后，脉冲电流导致谐波增加。

应试流程：确定电源相数 → 判断电流连续性 → 画触发脉冲 → 标出每个区间的导通器件 → 对输出波形积分。最后检查 $\alpha=0$、$\alpha=90^\circ$ 等极限是否符合直觉。

## 专题三：直流斩波与闭环调节

Buck 在连续电流下的理想电压变比为 $U_o=DU_d$；Boost 为 $U_o=U_d/(1-D)$；反相 Buck–Boost 为 $U_o=-DU_d/(1-D)$。这些关系来自电感伏秒平衡：稳态一个周期内电感平均电压为零。电容电荷平衡则给出输出纹波的数量级。

断续模式不能直接套连续模式公式，应先假设电感电流在一个周期内回到零，分别求导通、关断和零电流区间，再由峰值电流和平均电流建立关系。边界条件是谷值电流恰好为零，它可以用来求临界电感。

闭环题先画控制框图：参考值与反馈值比较，误差经补偿器和 PWM 产生占空比，功率级输出再反馈。补偿器的零极点用于提高低频增益、改善相位裕度；不能只看静态变比而忽略开关频率、采样延迟和电流限幅。

## 专题四：直流—交流逆变

半桥需要分压电容，全桥通过桥臂交替导通得到双极性或单极性输出。方波逆变简单但低次谐波大；SPWM 用正弦参考波与三角载波比较，调制度 $m_a$ 决定基波幅值，载波比决定开关频谱位置。三相桥要注意同一桥臂上下管不能同时导通，必须加入死区。

滤波器设计要同时考虑基波衰减、开关纹波和谐振峰。并网逆变器还需要锁相、限流、孤岛保护和电流环。题目给出调制波形时，先读出载波周期、占空比和开关状态，再求一个周期的平均值，不要把调制比直接当成输出有效值。

## 专题五：交流—交流变换与综合题

交流调压通过改变每半周的导通角调节有效值，适用于电阻或感性负载时波形差异明显。交交变频直接把低频交流合成为另一频率，输出频率受到电网频率和换相方式约束。矩阵变换器可实现无直流环节的能量变换，但需要复杂的开关约束和换流策略。

综合题可按“拓扑—状态—波形—指标—保护”五步写：先画结构，分状态列方程；再由平均值或傅里叶分析求指标；最后补充器件应力、死区、过流和过压保护。常见失分点是忽略负载类型、把峰值和有效值混淆、忘记续流和反向恢复。
