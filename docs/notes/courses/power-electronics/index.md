# 电力电子技术Ⅰ

电力电子课程研究“用半导体开关把电能变成需要的电压、电流和频率”。复习时不要只背拓扑图，要同时追踪开关状态、能量流向、波形平均值、器件应力和控制方式。下面按器件基础、整流、直流变换、逆变和交流变换组织。

## 五个专题

1. [器件、开关与波形建模](topics.md)：先建立理想开关、二极管、晶闸管和 MOSFET/IGBT 的统一语言。
2. [整流与功率因数](topics.md)：从单相半波、全控桥推进到三相整流和换相重叠。
3. [直流斩波与闭环调节](topics.md)：用伏秒平衡、状态空间平均和电感电容纹波分析 Buck/Boost。
4. [直流—交流逆变](topics.md)：比较方波、SPWM、三相桥和并网逆变器的调制与滤波。
5. [交流—交流变换与综合题](topics.md)：整理交流调压、交交变频和考试中的波形—器件—控制三联题。

## 复习检查

- 写出输入、输出、开关频率和负载类型；
- 逐个开关状态画等效电路，标出电感电流和二极管续流方向；
- 判断电感/电容工作在连续还是断续模式；
- 用平均值、伏秒平衡或功率守恒求主结果；
- 再检查器件耐压、峰值电流、散热和 EMI 风险。
