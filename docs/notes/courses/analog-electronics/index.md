# 电路与电子技术Ⅰ：模拟电子部分

[打开静态工作点、小信号与反馈学习路线 →](study-guide.md) · [回看秋学期电路部分 →](../circuit-theory/index.md)

冬学期模拟电子部分把半导体器件放进电路。每道计算题建议固定采用“**静态分析 → 动态分析 → 工作范围检查**”三段式：先判断器件工作区和静态点，再换成小信号模型求增益、输入/输出电阻，最后检查是否失真、饱和或超出频率范围。

## 器件状态先于公式

- **二极管**：先按题目给出的理想、恒压降或分段线性模型假设导通/截止；求出结果后反查假设是否成立。稳压管必须在反向击穿区工作，且电流不能超过题设范围。
- **BJT**：依据两个 PN 结偏置判断截止、放大或饱和。放大区常用 $I_C\approx\beta I_B$，但还要检查 $V_{CE}$ 是否留有放大区余量。
- **MOSFET**：先区分 N/P 沟道和增强/耗尽型，再用 $V_{GS}$、$V_{DS}$ 的不等式判断截止、线性区或饱和区；不能只凭电路图符号猜工作区。
- **运算放大器**：只有在线性负反馈且输出未饱和时才能使用“虚短、虚断”。正反馈、比较器和饱和状态必须改用非线性分析。

## 静态工作点

直流分析时，耦合电容和旁路电容开路，交流源置零。对 BJT 至少求出 $I_{BQ}$、$I_{CQ}$、$V_{CEQ}$；对 MOS 至少求出 $V_{GSQ}$、$I_D$、$V_{DSQ}$。静态点的意义是为交流信号留下摆幅空间：靠近截止会产生截止削顶，靠近饱和会产生饱和削顶。

建议在草稿上画出直流通路，并在结果旁写一句“工作区成立，因为……”。这句话能帮助发现用错模型的问题。

## 小信号与放大级

中频交流分析时，直流电源视为交流地，耦合/旁路电容按短路或题设阻抗处理，再围绕静态点线性化器件。常见结构：

| 结构 | 典型特点 | 计算重点 |
| --- | --- | --- |
| 共射 / 共源 | 电压增益较大，通常反相 | $A_v$、$R_i$、$R_o$、最大不失真摆幅 |
| 共集 / 源极跟随 | 电压增益接近 1，输入电阻高、输出电阻低 | 缓冲和带载能力 |
| 共基 / 共栅 | 输入电阻较低，高频性能较好 | 电流增益、阻抗和级间连接 |
| 差分对 | 放大差模、抑制共模 | $A_d$、$A_c$、CMRR 和尾电流 |

多级放大不能直接把各级空载增益相乘。前一级输出电阻与后一级输入电阻形成负载，应先求带载增益，再相乘；分贝增益才可以相加。

## 反馈、频率响应与运放

判断反馈按固定顺序：先看输出取样的是电压还是电流，再看输入端是串联还是并联混合，最后沿反馈路径标瞬时极性判断正负反馈。深度负反馈时可用 $A_f\approx1/F$ 作为近似，但必须确认环路增益足够大、系统没有进入振荡或饱和。

低频截止常由耦合和旁路电容造成，高频截止常由结电容、布线和米勒效应造成。带宽 $BW=f_H-f_L$；多级系统的总带宽不能只套用单级结果。

## 功率、稳压与振荡

- 甲、乙、甲乙类功率放大按导通角区分；乙类推挽要检查交越失真、最大输出功率、效率和管耗。
- 整流滤波后，稳压管或串联型稳压电路负责降低纹波并稳定输出；分别检查平均值、纹波和稳压管/调整管电流。
- 正弦振荡需要环路相位为 $2k\pi$，起振时环路增益大于 1，稳态时幅值逐渐回到 1。三角波/方波发生器常由积分器和滞回比较器构成，先找阈值再求周期。

## 期末题型地图

1. 概念辨析：多子/少子、漂移/扩散、器件工作区、反馈和频率响应。
2. 两级阻容耦合放大：静态点 → 每级小信号 → 级间带载 → 总增益。
3. 差分放大：差模/共模分解、尾电流、CMRR。
4. 反馈与运放：判组态、求闭环增益、检查线性范围。
5. 功放、稳压和振荡：分别抓导通角、纹波/调整范围、起振条件和阈值。
