# 02 模拟电子技术

[打开静态工作点、小信号与反馈学习路线 →](study-guide.md)

模拟电路分析要分清直流静态工作点与交流小信号模型。推荐顺序：识别器件工作区 → 建立偏置 → 求增益与输入输出电阻 → 检查幅度、频率和反馈。

## 半导体器件与工作区

PN 结正向偏置导通、反向偏置截止（击穿区除外）。硅二极管常用恒压降近似约 $0.7\,V$，以题设模型为准。稳压管需处于反向击穿区且电流不超额定范围；动态电阻 $r_z=\Delta V_Z/\Delta I_Z$。双极型晶体管先看结偏置，再判断截止、放大或饱和；放大区近似 $i_C=\beta i_B$。场效应管区分增强/耗尽、N/P 沟道，并按 $V_{GS},V_{DS}$ 判断工作区，不能只凭符号判定。

## 基本放大与静态点

静态分析时耦合、旁路电容开路，交流源置零；求 $I_{BQ},I_{CQ},V_{CEQ}$ 并检查工作区。中频交流分析时电容近似短路，直流电源为交流地。共射电压增益较高且反相；共集输入电阻高、输出电阻低，近似电压跟随；共基电流增益近 1，适合高频。削顶需区分截止失真和饱和失真。

## 多级、差分与频响

多级总增益是各级带负载增益的乘积，分贝增益相加。差分输入 $v_{id}=v_1-v_2$，共模输入 $v_{ic}=(v_1+v_2)/2$；$\mathrm{CMRR}=|A_d/A_c|$，分贝值为 $20\log_{10}(\mathrm{CMRR})$。低频截止常由耦合/旁路电容决定，高频截止常由结电容和米勒效应决定；带宽 $BW=f_H-f_L$。

## 负反馈与运放

输出端取样电压或电流，决定电压/电流反馈；输入端串联或并联比较，决定串联/并联反馈。先判断取样量，再标瞬时极性判断正负反馈。深度负反馈时 $A_f\approx1/F$。负反馈可稳定增益、减小失真、扩展带宽，但输入/输出电阻变化取决于反馈组态。理想运放在线性负反馈下才可用“虚短、虚断”；饱和或正反馈时不可套用。

反相放大器 $A_v=-R_f/R_{in}$，同相放大器 $A_v=1+R_f/R_g$。积分、微分电路还需考虑电容初始条件、带宽和饱和限制。

## 振荡、功率放大与电源

正弦振荡稳态满足环路相位为 $2k\pi$、幅值环路增益为 1；起振时环路增益需大于 1。功率放大按导通角区分甲、乙、甲乙类；乙类推挽关注交越失真。整流滤波后由稳压环节降低纹波并稳定输出，计算中分别检查平均值、纹波和稳压管电流。

## 易错点

- 先定静态点，不能用小信号公式求静态量。
- 反馈组态看输出取样和输入比较方式，不凭反馈元件名称猜。
- 分贝增益、线性增益不可混用，电压增益符号包含相位。
- 计算结果要与器件工作区相互验证。
