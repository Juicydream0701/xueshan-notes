# 电路与电子技术Ⅰ：模拟电子应试路线

模拟电子题最容易在“模型切换”处丢分。下面的步骤按考试答题顺序排列，适合把课件、概念题和综合计算题压缩成一套可执行流程。

## 一、所有计算题先做静态分析

1. **画直流通路**：耦合/旁路电容开路，交流源置零，保留直流电源和器件。
2. **假设工作区**：二极管导通/截止，BJT 截止/放大/饱和，MOS 截止/线性/饱和。
3. **列直流方程**：求 $I_B,I_C,V_{CE}$ 或 $V_{GS},I_D,V_{DS}$。
4. **反查假设**：电压极性、结偏置和工作区不满足时，换假设重新计算。
5. **标静态点**：把 $Q$ 点写在图上，估计输出最大不失真摆幅。

不要在静态分析阶段使用 $r_\\pi$、$g_m$ 或虚短虚断；这些属于围绕 $Q$ 点的动态近似。

## 二、再做动态分析

1. 直流电源改成交流地。
2. 依据频段决定耦合/旁路电容是短路、开路还是保留阻抗。
3. 画小信号等效电路，标出输入、输出和负载。
4. 求带载增益、输入电阻和输出电阻。
5. 检查增益相位、低频/高频限制和最大摆幅。

两级放大时，后一级输入电阻会加载前一级输出。正确顺序是“前级带载增益 → 后级带载增益 → 总增益”，不能把两个空载增益直接相乘。

## 三、题型—先画什么—检查什么

| 题型 | 先画什么 | 常见失分点 | 结果检查 |
| --- | --- | --- | --- |
| 二极管/稳压管 | 分段线性直流图 | 未反查导通或击穿条件 | 电流方向、稳压管工作电流 |
| BJT 静态点 | 直流通路与负载线 | 把饱和点当放大区 | $V_{CE}$、$I_C\\approx\\beta I_B$ |
| MOS 静态点 | $V_{GS}$、$V_{DS}$ 标注图 | 混淆线性区与饱和区 | 不等式和电流方向 |
| 单级放大 | 直流图 + 小信号图 | 直流电源未置交流地 | $A_v,R_i,R_o$ 单位与相位 |
| 多级/差分 | 分级等效图 | 忽略级间负载或尾电流 | 带载增益、CMRR |
| 负反馈 | 输出取样、输入混合框图 | 只看反馈电阻名字 | 正负、串并联、电压电流四分类 |
| 理想运放 | 先判线性/饱和 | 在比较器中套虚短 | 输出是否超电源轨 |
| 功率放大 | 导通角和负载线 | 混淆效率、管耗和输出功率 | 功率守恒、最大值条件 |
| 稳压电源 | 整流—滤波—稳压链 | 只算输出不查调整范围 | 纹波、压差、限流 |
| 振荡器 | 环路或阈值图 | 只写相位条件不写幅值条件 | 起振、稳态、周期 |

## 四、反馈题的固定四步

1. 从输出端沿反馈网络回到输入端，判断反馈信号对输入是增强还是抵消。
2. 判断输出取样：并联在负载两端通常是电压取样，串入支路通常是电流取样。
3. 判断输入混合：反馈信号与输入串联相加是串联混合，并联注入同一节点是并联混合。
4. 写闭环关系 $A_f=A/(1+AF)$，再根据拓扑说明输入、输出电阻和带宽的变化方向。

## 五、运放、功放和振荡的应试抓手

- **运放**：先判负反馈和输出范围，再使用 $i_+=i_-=0$、$v_+=v_-$；积分器还要写初始条件和饱和限制。
- **功放**：先写导通角，再区分负载输出功率、直流输入功率和晶体管管耗；乙类要说明交越失真。
- **串联稳压**：按整流平均值、滤波纹波、调整管压差和限流条件分段计算。
- **积分器 + 滞回比较器振荡器**：先求滞回阈值，再由积分器斜率求半周期，最后检查输出饱和幅值是否与阈值一致。

## 六、考前七天安排

- 第 7–6 天：二极管、BJT、MOS 工作区和静态点，各做一组并写反查条件。
- 第 5–4 天：单级、多级、差分和反馈，重点练画等效图。
- 第 3 天：运放、频响、功放、稳压、振荡，整理“题目关键词 → 方法”。
- 第 2 天：限时完成一套期末卷，标记卡顿位置。
- 第 1 天：只看错题、公式前提和常见图形，不再大量开新题。
