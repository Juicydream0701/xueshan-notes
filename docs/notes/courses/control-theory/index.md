## 题目训练：从指标反推方法

### 题 1：闭环传递函数与稳态误差

单位负反馈系统开环为 (G(s)=K/[s(s+2)])。先写闭环特征方程 (s^2+2s+K=0)，再用标准二阶形式判断阻尼比和自然频率。系统为 I 型，对单位阶跃输入的稳态误差为 0；对单位斜坡输入则由速度误差常数决定。使用终值定理前必须先确认 (K>0) 时闭环稳定。

### 题 2：劳斯表边界

若特征多项式的劳斯表第一列出现符号变化，变化次数就是右半平面根数。第一列首元素为零时，用正小量 (arepsilon) 代替并观察 (arepsilon	o0^+) 的符号；整行全零时，用上一行构造辅助多项式并求导。答题应写出特殊处理原因，不能直接跳到稳定区间。

### 题 3：二阶指标互相校验

标准欠阻尼二阶系统的超调量、峰值时间和调节时间分别受 (zeta) 与 (omega_n) 控制。若题目同时给出超调量和调节时间，先由

$$
M_p=\exp\left(-\frac{\pi\zeta}{\sqrt{1-\zeta^2}}\right)
$$

求 (zeta) 的范围，再用调节时间估计 (omega_n)，最后把参数代回完整闭环传递函数。只匹配超调而不检查调节时间，通常无法满足全部指标。

### 题 4：校正方案选择

若稳态误差过大而响应速度尚可，优先考虑提高低频增益的滞后校正；若相位裕度不足且需要提高带宽，可考虑超前校正。设计后必须同时验证开环 Bode 图、闭环极点、阶跃响应和控制量是否饱和。校正网络的每一个零点和极点都应说明“改变了哪个指标”。

## 统一答题模板

1. 写明输入、输出、反馈符号和初始条件；
2. 求闭环特征方程或开环频率特性；
3. 选择劳斯、根轨迹、Bode 或 Nyquist 中合适的工具；
4. 给出稳定性与性能指标，并标注适用假设；
5. 用极限、量纲或仿真结果做一次独立复核。
