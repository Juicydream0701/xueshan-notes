# 数字电子技术：逻辑设计与时序检查

数字电路题的关键是把文字要求变成明确的输入、输出、状态和时序约束。先确定逻辑功能，再选择实现形式，最后检查器件极性、传播延迟和状态恢复。

## 组合逻辑的标准步骤

1. 列出输入、输出定义和有效电平，必要时标明无关项的物理含义。
2. 建真值表，或从题目给定的功能式出发。
3. 用代数化简或卡诺图得到表达式，同时保留能解释功能的中间过程。
4. 选择门级、译码器、数据选择器或比较器实现，并检查扇入/扇出和输入极性。
5. 将化简结果代回关键输入组合，验证边界和易混淆状态。

卡诺图合并时只能按 $1,2,4,\ldots$ 个相邻格成组，边界可以相邻，不能斜向合并。无关项仅在确实不会出现或允许任意输出时使用，不能为了化简随意把有效状态标成无关。

## 竞争冒险与异步输入

逻辑等价不保证瞬态完全相同。不同路径的传播延迟可能形成短暂毛刺；对异步控制、时钟或敏感输出尤其要检查竞争冒险。必要时通过冗余项、同步化或电路结构避免毛刺影响。按键和外部信号通常需要考虑抖动、有效电平与同步采样。

## 时序逻辑分析

先从触发器特性方程写出下一状态，再用组合逻辑表达输入。D 触发器满足 $Q^+=D$；JK 触发器在 $J=K=1$ 时翻转；T 触发器在 $T=1$ 时翻转。接着列现态—输入—次态表，画状态图并检查未用状态的去向。

同步清零/置位在时钟边沿起作用；异步控制不等待时钟，优先级和有效电平须按器件表确定。时序约束要区分建立时间、保持时间、时钟到输出延迟和恢复/移除时间，不要把逻辑功能正确等同于时序可实现。

## 计数器与状态机

模 $N$ 计数器需要覆盖 $N$ 个有效状态。设计时确定触发器数量、状态编码、输入方程、输出方程和非法状态恢复。用同步计数器还是异步脉动计数器，应根据速度、译码毛刺和电路复杂度决定。状态机题先抽取状态，再定义转移条件，最后决定 Moore 或 Mealy 输出形式。

## A/D 与 D/A 的误差概念

理想 $n$ 位转换器有 $2^n$ 个量化码，量化步距由满量程跨度和码数定义；具体边界是否采用 $2^n$ 或 $2^n-1$ 的分母，取决于题目约定和器件定义。ADC 量化误差常以半个 LSB 讨论，实际误差还包含偏移、增益、非线性和噪声。不要把分辨率、精度和转换时间混为一谈。

## 复习路径

- 先熟悉数制、补码、BCD 和逻辑代数，练习从文字描述写真值表。
- 再做卡诺图与组合模块设计，重点核对低有效信号和无关项。
- 然后用特性方程完成触发器、计数器与状态机题，并检查非法状态。
- 最后集中练时序图、竞争冒险、A/D 与 D/A 的参数解释。
- 每道设计题保留一份“规格—方程—电路—验证”记录，避免只抄最终电路。
