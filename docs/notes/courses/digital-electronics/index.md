# 03 数字电子技术

[打开组合逻辑、时序逻辑与设计步骤 →](study-guide.md)

数字电路只处理有限逻辑电平，分析重点是逻辑表达、化简、组合电路和时序电路。

## 数制、逻辑代数与卡诺图

熟练进行二、八、十、十六进制互换，区分原码、反码、补码和 BCD 码。逻辑代数常用交换、结合、分配、吸收和德摩根定律；卡诺图按相邻 1（或 0）成 $1,2,4,\ldots$ 组，允许环绕和重叠，目标是得到最少项且覆盖全部目标格。

## 组合逻辑

组合电路输出只由当前输入决定。编码器/译码器要检查使能端和有效电平；多路选择器可实现逻辑函数；半加器、全加器级联得到多位加法器。比较器按最高位优先比较。设计步骤：列真值表 → 写标准式 → 卡诺图化简 → 选门电路实现 → 检查未使用输入。

## 触发器与时序逻辑

锁存器对电平敏感，触发器通常对边沿敏感。D 触发器 $Q_{next}=D$；JK 触发器在 $J=K=1$ 时翻转；T 触发器在 $T=1$ 时翻转。建立时间、保持时间和时钟边沿决定可靠采样，异步置位/复位优先级需按器件真值表处理。

## 计数器、寄存器与存储器

同步计数器各触发器共用时钟，异步计数器存在级联延迟。设计模 $N$ 计数器时先列状态转移，再选择触发器并化简激励方程，对无效状态规定恢复路径。移位寄存器可实现串并转换、延时与序列发生。存储器容量为“字数 × 每字位数”，地址线数量满足 $2^n$ 覆盖字数。

## DAC、ADC 与易错点

DAC 分辨率由位数决定，理想步长约为满量程除以 $2^n$；ADC 量化误差通常不超过 $\pm 1/2$ LSB。采样、保持、转换时间需满足系统时序。检查有效高低电平、竞争冒险、异步复位和补码溢出。

## 设计题的统一流程

遇到“用指定器件实现某功能”的题目，先不要急着画门电路。建议固定使用以下六步：

1. 写清输入、输出和有效电平，标出无关输入和禁止状态；
2. 列真值表或状态转移表，给每个状态分配编码；
3. 按题目要求选择最适合的器件（与非门、译码器、选择器或触发器）；
4. 化简逻辑表达式或激励方程，保留一份未化简式用于检查；
5. 画出带使能、复位和时钟的完整连接图；
6. 用边界状态、无效状态和时序最坏情况逐项验证。

组合逻辑题的核心是“输入变化后，输出只由当前输入决定”；时序逻辑题则必须同时说明时钟边沿、复位方式和状态保存位置。若题目要求异步清零，应在图中明确清零端的有效电平，不能只在文字中补充。

## 卡诺图、竞争和冒险

卡诺图分组的目标是覆盖所有目标项并尽量扩大圈组。圈组允许环绕、重叠，但每一组的格数必须是 (2^m)。化简后应做一次代数回代，检查是否遗漏了孤立的 1 或把无关项误当成必选项。

即使只有一个输入变量变化，也可能因原变量和反变量经过不同路径、传播延迟不等而产生静态冒险；多个输入同时变化还可能引入功能冒险，二者要区分。工程上可以通过增加共识项、采用同步采样或使用带锁存的结构抑制。考试中若题目问“如何消除竞争冒险”，应同时写出逻辑修改和时序上的替代方案。

## 时序分析与建立保持时间

对寄存器到寄存器路径，基本约束可写为

$$
t_{cq,\max}+t_{logic,\max}+t_{setup}\le T_{clk}+s,
$$

这里定义 $s=t_{\mathrm{capture}}-t_{\mathrm{launch}}$ 为捕获时钟相对发射时钟的到达延迟：$s>0$ 放宽建立约束，却收紧保持约束。$t_{cq}$ 是时钟到输出延迟，$t_{logic}$ 是组合逻辑延迟；建立检查取最大延迟，保持检查则要求 $t_{cq,\min}+t_{logic,\min}\ge t_{hold}+s$。若教材把 skew 定义为相反方向，公式中的符号也应同步改变。做时序题时要先画时钟和数据波形，再代入不等式，避免把建立时间和保持时间的方向写反。

同步计数器的设计顺序是：确定模数 → 列状态表 → 指定无效状态的回收路径 → 写各触发器激励 → 化简 → 检查最长组合延迟。对模 (N) 计数器，若 (N) 不是 (2^n)，必须明确多余状态如何处理，否则电路可能停在无效环路。

## ADC、DAC 与接口时序

理想 N 位 ADC 的量化步长近似为

$$
q=\frac{V_{max}-V_{min}}{2^N},
$$

满量程、参考电压和输入量程必须区分。计算转换结果时先判断输入是否超量程，再根据题目约定决定截断还是四舍五入。DAC 题除了分辨率，还要检查输出建立时间、满幅误差和运放饱和。

数字系统接外部按键或异步信号时，至少需要同步器和去抖动。两级触发器可以降低亚稳态传播概率，但不能把“概率降低”写成“完全消除”。对跨时钟域数据，应说明握手、异步 FIFO 或 Gray 码等方案。

## 应试复盘表

每道综合题完成后记录四项：题型（化简、时序、计数、转换）、第一步判断、最容易漏写的控制端、最后用什么边界状态验证。复习顺序建议为“数制与逻辑代数 → 组合设计 → 触发器 → 时序约束 → 计数/寄存器 → ADC/DAC → 综合设计”。这样既能覆盖计算题，也能为微机原理和 FPGA 实验建立共同语言。
