# 数字电子技术：逻辑、时序与器件分析

数字电路复习按“逻辑表达—门级实现—时序约束—器件特性”组织。做题先画状态或逻辑图，再写方程，最后用真值表或波形验证。

## 1. 数制、编码与逻辑代数

二进制、十六进制转换要注意位权和补码符号。补码加减的溢出由符号位判断，不能只看进位。逻辑代数中优先使用德摩根律、吸收律和卡诺图化简。卡诺图分组应取 (2^k) 个相邻格，允许环绕，但不能跨越无关项之外的格子。

## 2. 组合逻辑设计

组合电路输出只由当前输入决定。设计流程是：列真值表 → 化简逻辑函数 → 选择门电路或译码器/数据选择器实现 → 检查冒险。译码器实现多输入函数时先写最小项，数据选择器实现时按选择变量分组。

竞争冒险来自不同路径传播延时。静态 1 冒险可通过增加共识项消除；同步系统中还要关注输入建立时间和保持时间。

## 3. 锁存器、触发器与时序

锁存器电平敏感，触发器边沿触发。D 触发器下一状态由 (Q^+=D) 决定；JK 触发器在 (J=K=1) 时翻转；T 触发器在 (T=1) 时翻转。状态机设计先确定状态编码，再列现态/次态表和输出方程。

建立时间、保持时间、时钟到输出延时决定最高时钟频率。若出现亚稳态，不能用逻辑代数消除，只能通过同步器和足够的解析时间降低概率。

## 4. 计数器与寄存器

同步计数器的所有触发器共用时钟，异步计数器有逐级延迟。设计模 (N) 计数器要处理无效状态，必要时增加自启动逻辑。移位寄存器可实现串并转换、延迟和环形计数。

## 5. 存储器与可编程逻辑

RAM 读写时序要区分地址建立、片选、读写控制和数据保持。ROM、PLA、PAL 和 FPGA 的逻辑资源不同，题目常要求根据地址线、数据线和字数计算容量。

## 6. 模拟接口与器件参数

ADC 的量化步长约为满量程除以 (2^n)，量化误差通常不超过半个 LSB；采样前需满足奈奎斯特条件。DAC 关注分辨率、满量程误差和建立时间。施密特触发器利用滞回提高抗噪声能力。

## 7. 题型模板

- 卡诺图：先圈最大组，再写每组保留变量；
- 时序图：从有效边沿开始，按传播延时推进；
- 状态机：确认状态编码和无效状态处理；
- 计数器：写出模数、触发器数量和自启动条件；
- 存储器：用地址线数计算字数，用数据线数计算字长。
