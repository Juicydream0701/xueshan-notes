# 半导体物理：应试复习与公式检查

半导体物理的计算题通常不是“代公式就结束”，而是先判断材料、统计和边界条件，再决定使用哪一种近似。下面的清单适合考前压缩复习，也适合每次做题前写在草稿纸顶部。

## 一、先判断四个条件

| 先判断 | 典型选项 | 它决定什么 |
| --- | --- | --- |
| 热平衡？ | 热平衡 / 外加偏压或光照 | 是否使用单一费米能级、质量作用定律 |
| 统计区间？ | 非简并 / 简并 | 能否使用 Maxwell–Boltzmann 指数式 |
| 注入水平？ | 小注入 / 大注入 | 是否可忽略多数载流子变化 |
| 结和接触模型？ | 突变结 / 缓变结，理想 / 非理想 | 耗尽层、电容、I–V 公式的形式 |

题目没有明确说明时，先从课件默认的理想、非简并、热平衡模型开始，并把假设写在答案第一行。

## 二、通用解题流程

1. 画能带图或能级位置，标 $E_C,E_V,E_F$，必要时标准费米能级。
2. 判断本征、n 型、p 型和多数/少数载流子。
3. 统一单位：浓度常用 $\mathrm{cm^{-3}}$，迁移率用 $\mathrm{cm^2/(V\cdot s)}$，能量统一用 eV 或 J。
4. 先写物理关系，再代数值：电中性、质量作用定律、输运方程或边界条件。
5. 检查数量级、符号、温度趋势和极限情况。

## 三、常用公式卡

### 载流子统计

$$n_0p_0=n_i^2$$

$$n_0=N_Ce^{-(E_C-E_F)/kT},\qquad p_0=N_Ve^{-(E_F-E_V)/kT}$$

非简并 n 型且 $N_D\gg n_i$ 时，常近似 $n_0\approx N_D$；p 型且 $N_A\gg n_i$ 时，常近似 $p_0\approx N_A$，少数载流子再由质量作用定律得到。若补偿、低温冻结或重掺杂明显，必须停止这个近似并回到电中性方程。

### 输运与扩散

$$\sigma=q(n\mu_n+p\mu_p),\qquad \rho=1/\sigma$$

$$J_{drift}=\sigma E,\qquad \frac{D_n}{\mu_n}=\frac{D_p}{\mu_p}=\frac{kT}{q}$$

$$L_n=\sqrt{D_n\tau_n},\qquad L_p=\sqrt{D_p\tau_p}$$

扩散电流的符号要结合电子/空穴定义检查；不要只看浓度梯度的方向就直接写传统电流方向。

### pn 结

$$V_{bi}=\frac{kT}{q}\ln\frac{N_AN_D}{n_i^2}$$

$$I=I_S\left(e^{qV/kT}-1\right)$$

正偏时势垒降低、耗尽层变窄；反偏时势垒升高、耗尽层变宽。若题目问结电容或击穿，必须先判断是耗尽层电容、扩散电容、雪崩击穿还是齐纳击穿。

### 金属—半导体接触

$$W_m=E_0-E_{Fm},\qquad W_s=E_0-E_{Fs},\qquad \chi=E_0-E_C$$

接触题的安全做法是“先画接触前能级，再让费米能级对齐，最后标能带弯曲和界面电荷”。不同教材对势垒高度和接触电势的正负定义可能不同，符号必须跟随题目能级图。

## 四、按题型建立检查句

- **能带题**：我是否标出了参考能级、禁带宽度和费米能级？
- **掺杂题**：我是否先判断多数载流子，再由 $n_0p_0=n_i^2$ 求少数载流子？
- **电导题**：我是否同时考虑电子和空穴，并统一了迁移率单位？
- **非平衡题**：我是否声明小注入/大注入，并说明寿命和边界条件？
- **pn 结题**：我是否区分热平衡、正偏和反偏的电荷、电场和电流？
- **接触题**：我是否从功函数和能带弯曲判断整流，而不是只背压降？

## 五、考前复习安排

1. **第一轮（概念）**：按八章主线画三张图：$E-k$ 图、热平衡能带图、pn 结能带图。
2. **第二轮（计算）**：集中练载流子统计、电导率/扩散长度、内建电势、理想 I–V 和接触能级。
3. **第三轮（综合）**：做回忆卷，给每道题标注所用近似；错题按“能带、单位、统计、符号、边界条件”归类。
4. **最后检查**：只看公式前提和常见数量级，不再把教材或重复课件从头通读。
