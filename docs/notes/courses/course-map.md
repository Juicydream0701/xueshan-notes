# 课程导航与复习路径

这里是课程区的总入口。每门课都按“课程首页 → 分专题讲解 → 复习路线 → 原始资料”组织：先在首页确定范围，再进入专题页面学习，最后用速查页、题目和 PDF 做自测。页面中的 PDF 是从课程资料中筛选的公开学习材料；原始资料目录保持不变，未把含姓名、学号、联系方式、成绩或私人聊天记录的文件复制到网站。

## 建议的阅读顺序

### 先补基础

1. [微积分（甲）I–II](foundations/calculus/index.md)：极限、导数、积分、多元、级数和积分变换。
2. [线性代数（甲）](foundations/linear-algebra/index.md)：矩阵、线性映射、特征值和二次型。
3. [常微分方程](foundations/ordinary-differential-equations/index.md)：为电路暂态、控制和信号系统建立动态方程直觉。
4. [概率论与数理统计](foundations/probability-statistics/index.md)：处理实验误差、随机信号和建模数据。

### 再学专业主线

1. [电路与电子技术Ⅰ·电路](circuit-theory/index.md) → [模拟](analog-electronics/index.md) → [数字电子技术](digital-electronics/index.md)。
2. [信号分析与处理](signal-analysis/index.md) → [电网络](electrical-networks/index.md) → [控制理论（乙）](control-theory/index.md)。
3. [微机原理与应用](microcomputer/index.md) → [计算机网络与通信](computer-networks/index.md) → [宽带无线通信技术设计与实践](wireless-communications/index.md)。
4. [半导体物理](semiconductor-physics/index.md)与[工程电磁场与波](electromagnetics/index.md)用于补足器件和场的物理基础。

### 最后做工程实践

[电路与电子技术实验 II](circuit-electronics-experiments/index.md)、[电子测量与智能仪器](measurement-instruments/index.md)、[电力电子技术Ⅰ](power-electronics/index.md)、[工程训练](engineering-training/index.md)和[工程图学](engineering-graphics/index.md)适合在理论课之后按项目查阅。实验页面统一采用“原理—连接—计算—仿真—实测—误差分析”的顺序。

## 每门课页面应该怎样读

课程首页负责回答“学什么、先修什么、资料在哪里”；专题页负责回答“为什么、怎么推导、怎样做题”；复习路线负责回答“考试前如何压缩”；PDF 入口负责回答“回到哪一份原始材料核对”。遇到公式时先看符号和适用条件，遇到例题时先独立写出已知量、未知量和模型，再展开计算。

对于题目解答，网站优先保留解题路径、关键判断和验算方法。数字结果、课程符号和考试范围仍应回到授课讲义核对；页面中的整理内容用于复习，不替代教师发布的正式要求。

## 公开发布前的资料筛查

- 保留课程名称、章节、通用讲义、公开题目和匿名化的学习方法。
- 不上传成绩单、名单、含姓名学号的实验报告、联系方式、账号密码、私人聊天截图和未获授权的受限资料。
- 对 PDF 先检查首页、页眉页脚、批注和文件属性；发现个人信息时只保留经脱敏的知识页，或只在页面中提供文件说明而不复制原文件。
- 生活随感和公众号整理文章保留原作者、发布日期与原文链接，不把转载内容伪装成原创。

## 资料入口约定

课程中的 PDF 使用相对链接，统一放在对应课程的 `resources/` 目录；图片放在课程的 `images/` 或 `figures/` 目录。这样既能在网页中直接阅读，也能在 GitHub 仓库中按课程查找。新增资料时应同时补充课程首页或本页的入口，避免出现“文件已经上传但找不到”的情况。
