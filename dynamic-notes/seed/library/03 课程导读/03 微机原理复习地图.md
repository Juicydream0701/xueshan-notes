# 微机原理：外设配置的统一思路

微机题不要只背寄存器名称。建议把每个模块都按“时钟来源 → 控制寄存器 → 标志位 → 初始化 → 中断/轮询 → 验证”整理。完整章节在[静态主站微机原理复习区](https://juicydream0701.github.io/xueshan-notes/notes/courses/microcomputer/)。

## 复习顺序

1. **体系结构**：先画程序存储器、片内 RAM、SFR 和片外数据空间边界。
2. **指令与寻址**：区分 `MOV`、`MOVX`、`MOVC`，追踪累加器、进位位和堆栈变化。
3. **中断**：写清中断源、允许位、优先级、入口地址、现场保护和清除标志的时机。
4. **定时器/计数器**：先确定晶振和 12T/1T 内核，再计算计数初值；不要直接照搬别的芯片数值。
5. **串口**：明确帧格式、波特率、发送/接收标志和中断服务流程。
6. **接口扩展**：把地址、数据、控制信号和程序初始化一一对应。
7. **Cortex-M/STM32**：将 8051 中的“时钟—寄存器—标志—服务流程”迁移到 32 位外设。

## 一道综合题的检查清单

- 初始化前是否打开外设时钟；
- 中断是否同时打开总开关、外设允许位和 NVIC/优先级；
- 定时计算是否写出单位和溢出边界；
- 读写标志位后是否给出清除条件；
- 程序循环是否可能忙等、丢数据或重复响应。
