# 半导体物理：按考试要点复习

本页把八章内容压缩成“每章必须回答的问题”。需要推导、图像和模拟卷时，打开[静态主站的半导体物理复习区](https://juicydream0701.github.io/xueshan-notes/notes/courses/semiconductor-physics/)。

## 八章主线

1. **晶体结构与各向异性**：会用晶向、晶面和米勒指数描述结构，并说明为什么材料参数可能随方向变化。
2. **电子状态与能带**：理解允许带、禁带、有效质量与 $E-k$ 关系，知道模型假设的边界。
3. **杂质与缺陷**：区分施主、受主、补偿掺杂和缺陷能级，在能带图上标注相对位置。
4. **载流子统计**：在非简并近似下使用
   $$n_0p_0=n_i^2,\quad n_0=N_Ce^{-(E_C-E_F)/kT},\quad p_0=N_Ve^{-(E_F-E_V)/kT}.$$
5. **输运与导电性**：区分漂移和扩散，掌握电导率、迁移率、扩散系数以及爱因斯坦关系。
6. **非平衡载流子**：能解释产生、复合、寿命、扩散长度和准费米能级，写出连续性方程的物理含义。
7. **pn 结**：从空间电荷区和内建电势出发，推导耗尽近似下的电场、势垒、I–V 和结电容。
8. **金属—半导体接触**：比较整流接触与欧姆接触，能从功函数、电子亲和能和界面态解释势垒变化。

## 应试时每道计算题都写清楚

- 温度、掺杂、材料是否均匀，以及是否采用非简并近似；
- 小注入还是大注入、低场还是高场、突变结还是缓变结；
- 公式的单位和边界条件；
- 最后用数量级、极限或能带图检查结果。
