# 电路原理：从模型到综合题

这是一份给复习使用的“路线卡”，把电路题拆成可以重复执行的步骤。详细推导、图示和逐题训练保留在[静态主站的电路原理讲义](https://juicydream0701.github.io/xueshan-notes/notes/courses/circuit-theory/)，本页用于在动态资料库里快速定位。

## 一、先判断题目处于什么状态

1. **直流稳态**：电容视为开路，电感视为短路；先确认题目是否真的已经达到稳态。
2. **正弦稳态**：统一采用有效值相量，电阻、电感、电容分别替换为 $R$、$j\omega L$、$1/(j\omega C)$。
3. **换路暂态**：保留储能元件，先求 $0^-$，再用连续性得到 $0^+$，最后求终值和时间常数。
4. **非正弦或三相**：先拆分频率、相序和对称性，再分别建立方程；不同频率的相量不能直接相加。

## 二、八个专题的最短复习顺序

| 专题 | 先掌握什么 | 做题时最容易错在哪里 |
| --- | --- | --- |
| 模型与定律 | 参考方向、被动符号约定、KCL/KVL | 把负号当成算错，或漏写受控源控制量 |
| 节点与网孔 | 选未知量、超节点、超网孔 | 电压源约束和电流源约束漏掉 |
| 网络定理 | 叠加、戴维南/诺顿、测试源 | 把受控源错误置零，或把功率直接叠加 |
| 正弦稳态 | 相量、复功率、功率因数 | 峰值与有效值混用、共轭方向错 |
| 一阶暂态 | 初值、终值、$\tau$ | 直接套公式，没有重新画换路后的等效电路 |
| 二阶暂态 | 阻尼类型、特征根、自然响应 | 判别式和单位不一致 |
| 三相电路 | 线量/相量换算、两表法 | 不平衡负载套用对称公式 |
| 耦合与二端口 | 点标记、反射阻抗、参数矩阵 | 电流参考方向变换时符号未同步 |

## 三、可以反复使用的解题模板

**节点法**：选参考节点 → 标注未知节点电压 → 写每个节点的 KCL → 对超节点补充电压约束 → 解完检查单位与功率平衡。

**戴维南等效**：拆出端口 → 求开路电压 $V_{th}$ → 独立源置零并保留受控源 → 用测试源求 $R_{th}$ → 接回负载并检查极限情况。

**一阶暂态**：求 $x(0^-)$ → 写 $x(0^+)$ → 求 $x(\infty)$ → 从储能元件端口看出去求 $R_{eq}$ → 写

$$x(t)=x(\infty)+[x(0^+)-x(\infty)]e^{-t/\tau}.$$

**结果检查**：量纲、初值、终值、极限、功率守恒至少检查两项。若答案看起来违反开路/短路直觉，应先回到模型而不是继续化简。
