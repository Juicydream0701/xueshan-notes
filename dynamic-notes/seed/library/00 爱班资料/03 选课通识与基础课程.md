# 选课、通识与专业基础课程

## 选课规则经验

选课页面中的“本专业待定人数”只能作参考，人数通常不是实际筛选人数。真正选课时，教务会按培养方案推荐学期、年级和大类筛选：

- 培养方案中有这门课，通常可以享有本专业待定资格；
- 培养方案中没有这门课，且本专业人数已经超过遗留名额，跨类选课很难成功；
- 低定选时可关注“所选课学分 + 补选学分 ≤ 22”的限制；
- 补选可联系开课学院教务；
- 转专业学生通常按座位量而不是页面容量筛选；
- 一轮优先同大类、同年级培养方案课程，二轮才考虑跨大类或跨年级；一轮已满时，跨类学生可能直接被筛掉。

以上是个人咨询和当年选课的经验总结，不替代本学期教务通知。

## 通识课

### 马克思主义基本原理

fr 老师课堂氛围相对友好。期末不能只靠临时背零散答案，劳动价值论等概念题要按知识体系背诵，确保要点完整。

### 心理健康与心理咨询

建议提前看课程考核构成和往年回忆题，关注老师当年的评分习惯和课堂要求。

### 英语议会制辩论

适合想训练英语表达和思辨能力的同学。课堂可能有较多练习和拖堂，但整体体验有趣，建议认真参与。

## 专业基础课

### 大学物理Ⅱ

wcj 老师强调基本训练：建立坐标系时先选参考点，分析力学和电学问题时明确方向与零点；使用定理时确认前提条件。竞速小测可以通过历年卷和小测归纳提升，但大学物理更适合持续复习，临时速成很难内化。

推荐流程：预习了解全貌 → 带问题听课 → 用笔记重建框架 → 独立完成作业 → 再查看答案和 AI 解释。

### 概率论与数理统计

wgz 老师的线下小测题型相对稳定，前几次班级的题目可用于总结考点。期末计算量较大，区间估计、假设检验等内容需要理解和刷题，不建议最后几天才开始。

### 复变函数与积分变换

yht 老师的短学期课程难度较高。平时整理定义、定理、积分方法和典型题，期末前集中刷题通常比只看讲义有效。

### 大学物理实验

实验报告检查可按“页码 → 标题层级 → 原句 → 错误原因 → 修改句”的顺序，让 AI 只找较大的语法、逻辑和专业知识错误，避免把时间浪费在无关紧要的措辞上。最终仍需自己核对实验数据和物理结论。

## 其他课程

- 形势与政策：平时考勤、作业讨论和研究性学习占比高，课堂发言和专题展示可以争取加分。
- 中国共产党历史：按老师要求准备党史书和史纲教材，详情参考课程资料帖。
- 定向越野：课程包含玉泉、植物园和华家池路线，也会涉及运动和健康知识。
- 打开艺术之门——琵琶：适合零基础，但每周需安排固定练习；期末曲目先保证完整性，再处理轻重强弱。
- 创业基础：小组展示和读书报告是重点，建议尽早协商分工和评分标准。
- 法学基础：小组展示通常整体评分，负责的组长和清晰分工很重要。
