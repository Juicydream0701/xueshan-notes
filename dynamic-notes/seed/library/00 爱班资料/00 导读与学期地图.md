# 爱班资料分享：导读与学期地图

这套资料来自爱班同学的课程经验、实验报告和学习复盘。内容按“课程经验 → 资料入口 → 个人方法”整理，适合在选课、备考或安排实验时快速查阅。

## 一年课程节奏

爱班理论课和实验课交错推进，真正需要提前规划的是夏学期。秋学期以小车实验和电路、模电基础为主；冬学期有电路原理实验和理论课复习；春学期进入电网络实验、模电音频功放等综合任务；夏学期集中出现信号心电采集、微机旋转钟、数电数字钟以及工程电磁场与波等内容，课程和实验压力都较大。

| 时段 | 主要任务 | 经验提醒 |
| --- | --- | --- |
| 秋 | 小车实验、电路基础、数电/模电入门 | 尽早熟悉仪器和实验报告格式 |
| 冬 | 电路原理实验、模电理论 | 模电不要等到期末临时突击 |
| 春 | 电网络实验、音频功放、信号与电网络课程 | 焊接、虚焊和调试需要预留时间 |
| 夏 | 心电采集、旋转钟、数字钟、微机和工磁复习 | 尽量不要叠加过多额外课程 |

1. 先看[课程与实验经验](01%20课程经验与实验安排.md)，了解每门课的难点和先后关系。
