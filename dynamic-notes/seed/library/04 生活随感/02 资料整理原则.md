# 资料整理原则

资料库的价值在于下次能找到，而不是文件数量多。每放入一份资料，尽量补上三个信息：它解决什么问题、适合什么时候读、读完要留下什么结果。

## 推荐的文件命名

`课程-专题-用途-日期`。例如 `电路-暂态-复习提纲-2026.md`，避免使用“最终版”“新建文件夹”等无法检索的名字。

## 资料分层

- **导读**：告诉读者先看什么；
- **讲义**：解释概念、假设、推导和例题；
- **原题/PDF**：保留原始题面，用于练习和核对；
- **复盘**：记录错因、验证和下一次行动。

重要文件同时保留在 GitHub 仓库或本地硬盘。Render 免费服务的运行时上传适合临时分享，不适合作为唯一存档。
